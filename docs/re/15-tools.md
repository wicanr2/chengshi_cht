# 15 — 玩家工具與自動接線

**推論等級：已確認**（一手出處 `w_tool.c`、`w_con.c`）。日期 2026-08-29。
接線：`internal/sim/tool.go`、`internal/sim/connect.go`。

## 一、工具是規則層

放置會扣錢、改地圖、觸發自動推土與自動接線，而且改完的地圖立刻餵給
下一刻的模擬。UI 只負責把滑鼠座標換算成格子座標。

## 二、指標算術的方向陷阱

`w_con.c` 全程用指標存取鄰居：

```c
Tile = TileAdrPtr[WORLD_Y];   /* 右邊 (x+1, y)   */
Tile = TileAdrPtr[-WORLD_Y];  /* 左邊 (x-1, y)   */
Tile = TileAdrPtr[1];         /* 下面 (x, y+1)   */
Tile = TileAdrPtr[-1];        /* 上面 (x, y-1)   */
```

地圖配置成一整塊記憶體，每欄 `WORLD_Y` 個 `short`，欄指標指進去。
所以 **`[1]` 是 +y 不是「下一格 x」**，`[WORLD_Y]` 才是 +x。

看到 `[1]` 直覺會讀成「下一個元素＝右邊一格」。讀錯的話接線表的四個
位元整組轉九十度，而畫面上**看起來幾乎是對的**——直路仍然是直路，
只有轉角與丁字會錯。這是典型的「自洽但錯」。

## 三、`NeutralizeRoad` 決定連通判斷的正確性

道路圖塊 64–207 分成三段：無車流、輕度、重度，低四位是形狀。

```c
#define NeutralizeRoad(Tile) \
  if (((Tile &= LOMASK) >= 64) && ((Tile & LOMASK) <= 207)) { \
    Tile = (Tile & 0x000F) + 64; }
```

判斷連通性前一定要先還原。忘了做的話，**塞車的路段會被判成不能接**，
而且只在車多的時候才出錯——症狀隨機、難以重現。

## 四、`fixSingle` 不是逐位元的不動點

它寫回去的是 `表[adj] | BULLBIT | BURNBIT`（電線多一個 `CONDBIT`），
所以會順手清掉**車流量與 `PWRBIT`**。在一座跑過的城市上逐位元比較
一定會不同，那是正常行為。真正的不變量是**形狀**。

拿八座劇本城市（原版資料）驗證：15 447 格線路裡 15 421 格的形狀
與 `fixSingle` 的輸出一致（99.83%）。

剩下的 26 格是**原版資料本身就過期**：火災、爆炸、洪水與分區成長都直接
覆寫格子，不會回頭對鄰居跑 `fixSingle`，所以會留下指向空地的接頭。
分布支持這個解釋——漢堡（大轟炸）12 格、里約（洪水）8 格，兩個災難劇本
就佔四分之三；東京、底特律各 1 格。逐格檢查也一致。

## 五、`Rand(4)` 是五個值

公園有五分之一機率是噴泉：

```c
value = Rand(4);
if (value == 4) tile = FOUNTAIN | ...;
else tile = (value + WOODS2) | ...;
```

`Rand(n)` 回傳 **0..n（含）**，見 [`02-rng.md`](02-rng.md)。
把它讀成 0..3 的話 `value == 4` 永遠不成立，噴泉整個消失——
而且沒有任何錯誤訊息。

## 六、幾個容易照抄錯的細節

| 位置 | 細節 |
|---|---|
| `check3x3` / `check4x4` / `check6x6` | 開頭一律 `mapH--; mapV--`。**點擊點是左上角往右下一格**，3×3 時剛好是中心，4×4 與 6×6 不是。|
| `check4x4` | `(1,2)` 那一格加 `ANIMBIT`（發電廠冒煙、核電廠冷卻塔）。只有 `aniFlag` 為真的建物才有。|
| `fixZoneBorder` | 四條邊各跑 n 格，**四個角落不跑**。|
| `putRubble` | 起點是 `(x-1, y-1)`，範圍 n×n——不是以中心為準的對稱範圍。輻射瓦礫與空地不會被覆蓋。|
| `bulldozer_tool` | 推水要 **6 元才動手，但只扣 5 元**。|
| `bulldozer_tool` | `checkBigZone` 回傳 3 的情形**只播音效，不放瓦礫**。|
| `_LayDoze` | 推掉橋、水下電纜、水下鐵路要還原成 `RIVER`，不是 `DIRT`。少了那張清單，拆橋會憑空生出陸地。|
| `_LayWire` 水下段 | 先看鄰居有沒有 `CONDBIT`，**才**做 `NeutralizeRoad`。順序反過來會把旗標抹掉。|
| `tally` | 第三段範圍是 `TINYEXP … LASTTINYEXP + 2`，原始碼旁邊留著 `/* ??? */`——作者自己也不確定那個 `+2`。照抄。|

## 七、還沒接的部分

- **多人模式的昂貴建物投票**（`Players > 1 && cost >= Expensive`）：
  回傳碼 `-3` 已經定義，判斷邏輯留給呈現層。
- **粉筆／橡皮擦**（`chalkState`／`eraserState`）：那是 Micropolis 的多人
  標註功能，原版 SimCity 1 沒有，不影響模擬。
- **拖曳**：原版的 `ToolDrag` 沿路徑逐格呼叫同一支工具，屬於輸入處理。
