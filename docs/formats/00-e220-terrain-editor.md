# 地形編輯器磁片（軟體世界，1990）— 盤點

`E220-1.ZIP` 與 `E220-2.ZIP` 是 Maxis **SimCity Terrain Editor** 的軟體世界版。
玩家自備，不入版控、不進發行包（[`CLAUDE.md`](../../CLAUDE.md) §8）。
解開到 `workplace/e220/`。

磁片裡的 `README` 全文只有一個方框：

```
+-------------------------------------+
| (C) 1990 SOFT-WORLD RESEARCH CENTER |
|  P.O.BOX 28-34,KAOHSIUNG,TAIWAN,ROC |
|       BBS  TEL : (07) 384-8901      |
+-------------------------------------+
```

還有一個零位元組的磁碟標籤檔 `SOFTWORLD`。與珍藏版 29 中文說明書是同一個代理商。

## 這片磁片解決了什麼

### 一、六種顯示模式的 `.PPF` 版面

編輯器的招牌畫面六種模式各一份，其中三種是本專案第一次拿到樣本。
版面與裁決方式見 [`06-ppf-screen.md`](06-ppf-screen.md)：
Tandy 與 sega 同版面、MONO 是 640×347×1 平面、CGA 是**封裝式 2bpp**。

⚠ 這**沒有**補上 [`../../CLAUDE.md`](../../CLAUDE.md) §2.1 記的那個缺口。
那裡缺的是**遊戲**的 CGA 與 Tandy 圖形集（`*CGA.PGF`／`*TDY.PGF`），
這片磁片給的是**編輯器**的美術。解碼器現在認得那三種版面，但沒有遊戲檔案可以餵。

### 二、城市檔檔頭的長度前綴不可盡信

十一個城市檔裡，`TAIWAN`（名稱 6 字）、`KAOHSIUN`（8 字）與 `Joffebrg.cty`（12 字）
的長度前綴一律寫 13，其餘的前綴確實等於字串長度。
解讀規則因此是「取前綴長度再切到第一個 NUL」，見
[`01-city-file.md`](01-city-file.md) §三。

### 三、128 位元組檔頭的第三次確認

十一個沒見過的檔案全部用檔頭 128 解出合理的純量；改用 144 每一個都是垃圾。

### 四、`SOUNDDAT.PSF` 哪一份是原廠內容

磁片上那份與 `DATA/SOUNDDAT.PSF` 逐位元相同，與根目錄那份不同。
見 [`../re/16-dos-oracle.md`](../re/16-dos-oracle.md) §八。

## 沒有做的事

- **`TERRAIN.EXE` 沒有反組譯。** Micropolis 不涵蓋地形編輯器（那裡的 terrain
  只有地形產生器 `generate.h`），所以要重製它得走反組譯這條退路
  （[`../../CLAUDE.md`](../../CLAUDE.md) §2.4）。它是 1990 年的獨立商品，
  不是遊戲的一部分，做不做是產品範圍問題。
- **六個 `.PGF` 沒有解。** 它們是沒有橫幅的「基本檔」版面，模式不寫在檔案裡。
- ~~**CGA 的四色盤沒有解。**~~ **不需要解**：CGA 是 `SIMCITY.CFG` 表上寫的
  **CGA Monochrome**，640×200 兩色，沒有四色盤。原本把 `.PPF` 讀成
  320 寬的兩位元封裝式（畫得出一幅看得懂的招牌），2026-09-04 由原版實跑
  更正，見 [`06-ppf-screen.md`](06-ppf-screen.md)。
