# 繁體中文攻略

`CLAUDE.md` §3.1 給這個目錄的定位是「社群攻略、雜誌回顧，繁中化，標明來源與版本」。
實際做出來的東西不一樣，理由要先講清楚。

## 為什麼不是翻譯社群攻略

`CLAUDE.md` §1.1 把社群攻略排在證據優先序的**最後一位**，並且點名這款遊戲的
玩家共識「量大、講得很篤定，而且經常是錯的或跨代混用的」——同一節就舉了三個
現成的錯誤例子。翻譯一份不可靠的東西，只是把不可靠變成繁體中文。

所以這裡寫的是**以本專案讀出來的原始碼為根據的攻略**：每一條策略後面附上
它出自哪一個機制，能標行號的就標。社群說法只在「訂正」那一節出現，
而且逐條說明它錯在哪、正確的是什麼。

這也是這份攻略唯一能贏過網路上既有攻略的地方：**它知道程式實際怎麼算。**

## 版本

本攻略描述的是 **DOS 1.10**，規則層以 Micropolis（EA 2008 GPL-3.0 釋出的
SimCity 原始碼）為準。**不適用於 SimCity 2000 之後的任何一代**——
跨代混用正是社群說法最常見的錯誤來源。
