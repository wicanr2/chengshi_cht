# 控制方式規格

**推論等級：已確認（原版有的部分）／本專案新增（其餘）**。日期 2026-08-29。
接線：`internal/ui/game.go`。

## 一、一手證據

原版 DOS 版的按鍵有兩份互相獨立的一手來源，而且**兩份一致**：

1. **《模擬城市參考附表》**——夾在軟體世界說明書裡的活頁，正面就是一張
   鍵盤線稿，逐鍵拉線標注。轉錄在
   [`docs/manual-cht/ref-card.md`](../manual-cht/ref-card.md)。
2. **DOS 1.10 的訊息檔 `DATA/*_MSG.PTF`**——第 19 段（速度副選單）自己印著
   `最快 4`／`快速 3`／`普通 2`／`慢速 1`／`暫停 0`。**選單文字本身就在告訴
   玩家按哪個數字鍵。**

第 2 點是在轉錄參考附表之後回頭比對才注意到的：那組數字**一直在我們自己的
翻譯檔裡**（`tools/i18n/base_zh.py` 第 19 段），只是沒有人把它當成按鍵證據讀。

## 三、remake 目前的對應

### 已照原版

`0`–`4` 速度、`B` 堆土機、`R` 道路、`P` 電力線、`T` 鐵軌、`Q` 質詢、
`Shift` 加速捲動、`Esc` 關視窗、
`Ctrl-A`／`Ctrl-B`／`Ctrl-C`／`Ctrl-E`／`Ctrl-G`／`Ctrl-H`／`Ctrl-M`／
`Ctrl-S`／`Ctrl-U`、`Alt-D`（災難選單）。

### 本專案新增（原版沒有給這些工具鍵）

`K` 公園、`Z` 住宅區、`X` 商業區、`V` 工業用地、`O` 警察局、`F` 消防隊、
`S` 體育館、`G` 燃煤電廠、`J` 核電廠、`H` 海港、`A` 機場。

原版這些工具只能點工具列選；remake 把工具列與快速鍵都留著。
舊版用的 `D`（堆土機）與 `W`（電力線）保留成別名，`F1`–`F4` 也保留成
速度的別名——既有的說明與試玩腳本因此不會失效。

### 已知的差距

| 項目 | 現況 | 為什麼 |
|---|---|---|
| 原版有**五段**速度，`SimSpeed` 只有四段 | 五段都接得起來 | **已解。** Micropolis 的 `setSpeed` 把參數夾在 0–3（`w_util.c:145`），但它另外有 `setSkips`／`sim_skips`（`sim.c:71`）——**一個畫格多跑幾次模擬**。第五段「最快」就是 `SimSpeed 3` ＋ 一個畫格跑三次，不是第五個速率。接在 `internal/ui/game.go` 的 `simSpeedOf`／`simFramesPerTick` |
| `Ctrl-L` 讀取城市 | **已接**（讀 `-save` 指的那個檔）| 原版會開檔名對話框；remake 讀固定路徑，對「存了檔想接著玩」夠用，不必做檔案瀏覽器 |
| `Ctrl-X` 離開 | **已接** | |
| `Tab` 前往災區 | 沒接 | 需要「上一個訊息的座標」這個狀態 |
| 數字鍵盤九向移動、`ScrollLock` | 沒接 | remake 用方向鍵捲動 |
| `Y`／`N` | 沒接 | remake 沒有需要是非作答的對話框 |
| `Alt-S`／`Alt-O`／`Alt-D`／`Alt-W` 選單 | **已接**（2026-08-30 的介面改版加了選單列與四個下拉選單，`internal/ui/menubar.go`）| |
| `F2`–`F5` 拉四個選單 | **已接**（2026-08-30）| 先前被拿去當速度的別名，與原版衝突。逐鍵實測裁決後改正，見 §五 |
| `F7`–`F10` | 沒接 | 軟體世界參考附表說 `F7F8` 視窗、`F9F10` 隱藏前視窗，但那份對應的前半段已被實測推翻（見 §五），後半段未驗 |
| `Ctrl-P` 移動前視窗 | 沒接 | remake 的視窗可以用滑鼠拖 |
| `Ins`／`Space` 當左鍵、`Del` 當右鍵 | 沒接 | remake 假設有滑鼠 |
| 方向鍵移游標（`Ctrl` ＋ 方向鍵才捲動）| 行為不同：remake 的方向鍵直接捲動 | 刻意的取捨，見上 |
| 數字鍵盤九向、`ScrollLock`、`+`／`-` 熱點循環 | 沒接 | 同上 |
| `Ctrl-P` 視窗位置、`Ctrl-R` 調整編輯窗大小 | **有接** | `Ctrl-R` 進調整模式（方向鍵一次一格）；視窗位置改成直接拖標題列 |

## 三之二、災難選單（`Alt-D`）

原版是下拉選單，六個項目照訊息檔第 20 段：火災、水災、空難、龍捲風、
地震、怪獸（第 7 筆是「取消」）。remake 做成視窗，上下鍵選、Enter 發動。

六個項目直接對到 `internal/sim` 的六支，與原版的選單一一對應
（`res/whead.tcl:271` 起：`sim MakeFire`／`MakeFlood`／`MakeAirCrash`／
`MakeTornado`／`MakeEarthquake`／`UIMakeMonster`）。

⚠ 原版的 `UIMakeMonster` 寫成 `sim MakeMonster [sim Rand 120] [sim Rand 100]`，
但 C 那邊的 `MakeMonster()` **不吃參數**、自己挑位置——那兩次 `Rand` 是
介面層白抽的（同 `docs/re/12` §6之五）。remake 不抽。

## 三之三、系統選單（`Alt-S`）

原版的系統選單（訊息檔第 17 段）有九項。remake 接了六項：

| 項目 | remake |
|---|---|
| 讀取圖形集 | 副選單，七個（`base` ＋ 六個資料片）。**圖塊與文字一起換**——古代亞洲的發電廠叫「水井」，只換圖不換字是半套 |
| 讀取悲情城市 | 副選單，八個劇本 |
| 重新建造一新城市 | 開「市名欄 ＋ 技術等級」對話框（照原版版面），按確定才產生新地圖。資金隨等級：簡易 $20,000、適中 $10,000、艱難 $5,000 |
| 讀取舊有檔案 `Ctrl-L` | 讀 `-save` 指的那個檔 |
| 儲存現有城市 `Ctrl-S` | 有 |
| 跳出遊戲 `Ctrl-X` | 有 |

沒接的三項：**關於本遊戲**（remake 沒有對應的畫面）、**印表**、
**以……檔名儲存**（要檔名輸入框）。

在這個選單接起來之前，換劇本、換圖形集、開新城市、讀存檔
**全部只能靠命令列參數**——玩家要玩第二個悲情城市得先關掉遊戲重開。

## 四、這條線抓到的一個真的 bug

改之前，遊戲內的速度副選單顯示「暫停 0／慢速 1／普通 2／快速 3／最快 4」，
而按下那些數字鍵會**放住宅區、商業區、警察局**——選單在叫玩家按一組
做別的事的鍵。翻譯是對的（照原版訊息檔），錯的是按鍵表；而兩邊分屬
不同檔案，所以單元測試與逐 frame 對拍都不會發現。

> 教訓寫成規則：**畫面上的字也是規格。** 從原版資料檔翻出來的字串，
> 只要提到操作方式（按鍵、順序、單位），就要回頭檢查程式有沒有照做。

## 五、功能鍵：已用 DOS 原版逐鍵裁決（已確認）

`F1`–`F10` 在原版是**拉選單**。兩份一手資料對「哪個 F 鍵開哪個選單」說法不同：

| 來源 | 對應 |
|---|---|
| 官方英文手冊（OCR 第 930–936 行）| `F2` 系統／`F3` 功能／`F4` 災難／`F5` 視窗，並註明沿用 Tandy Deskmate |
| 軟體世界《模擬城市參考附表》 | `F1F2` 系統／`F3F4` 災難／`F5F6` 功能／`F7F8` 視窗／`F9F10` 隱藏前視窗 |

**2026-08-30 用 DOS 原版逐鍵實測，一次一個鍵、每次從乾淨狀態開始**
（`tools/dosbox/act-m-F*.txt`，畫面存在 `workplace/dosbox/mF*-menu.png`）：

| 鍵 | 實測結果 |
|---|---|
| `F1` | **不開選單** |
| `F2` | **SYSTEM** |
| `F3` | **OPTIONS** |
| `F4` | **DISASTERS** |
| `F5` | **WINDOWS** |

**英文手冊那組正確；軟體世界參考附表那組對 DOS 1.10 不成立**
（註記寫在 [`../manual-cht/ref-card.md`](../manual-cht/ref-card.md)，
轉錄本身照原樣不改——那是保存，不是勘誤）。

順帶拍到四個選單的完整項目，可以拿來對 remake 的選單內容：

| 選單 | 項目 |
|---|---|
| SYSTEM | `About SIM CITY`／`Print`／`Load Graphics`／`Load Scenario`／`Start New City`／`Load City Ctrl-L`／`Save City as ...`／`Save City Ctrl-S`／`Exit Ctrl-X` |
| OPTIONS | **`Auto-Plow Ctrl-A`**／`Auto-Budget`／`Auto-Goto`／`Sound On`／`Speed`／`Animate all`／`Frequent animation` |
| DISASTERS | `Fire`／`Flood`／`Balloon Crash`／`Twister`／`Earthquake`／`Tumbleweed` |
| WINDOWS | `Maps Ctrl-M`／`Graphs Ctrl-G`／`Budget Ctrl-B`／`Edit Ctrl-E`／`Evaluation Ctrl-U`／`Close Ctrl-C`／`Hide Ctrl-H` |

⚠ 選單上寫的是 **`Auto-Plow`**，不是手冊正文說的 `Auto-Bulldoze`。
畫面上的字才是玩家看到的字。

### remake 已改

`internal/ui/game.go`：`F2`–`F5` 改成拉四個選單（與 `Alt-S/O/D/W` 並存），
**移除 `F1`–`F5` 的速度別名**。速度鍵是 `0`–`4`，那才是原版的
（訊息檔第 19 段自己印著）。`tools/playtest_inner.sh` 裡兩處用 `F1`／`F4`
控速的也一併改成 `0`／`4`。

### 這一輪踩到的三個坑（下次直接避開）

1. **遊戲要用 `RUN=simcity` 起。** 不給的話 DOSBox 停在 `C:\>`，
   動作腳本照樣跑完、截圖照樣產出——按鍵全被打進命令列
   （截圖上看得到 `:\>04rb`）。**第一輪就是這樣得到「F 鍵沒有反應」的假結論。**
2. **手冊查驗對話框會吃掉所有按鍵**，而且有兩層：先是
   `Enter NAME of city / Page:`（按 `Return` 送空白），
   再來是 `Congratulations, you passed.`（要點 Continue，遊戲座標 311,189）。
   沒關掉的話逐鍵截圖全部零像素差，看起來像「這個鍵沒有功能」。
3. **開場座標要抄 `act-ingame.txt`**（`click 200 197` → `click 311 245`），
   別抄 `act-menu-probe.txt`——那一支是別的流程。

> 教訓寫成規則：**在原版上下「這個鍵沒有作用」的結論之前，
> 先按一個已知會改變畫面的鍵。** 這一輪三次假陰性，三次都是這條擋下來的。
