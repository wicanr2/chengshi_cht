# 地形編輯器 — 規格

**狀態：READY**（版面與預設值來自反組譯，等級：已確認；未解項逐條標明）

證據來源：`workplace/e220/TERRAIN.EXE` 解 LZEXE 0.91 之後的 325 728 位元組版本，
IDA 資料庫 `workplace/ida/TERRAIN.EXE.i64`（輸入檔 SHA-256 前 16 碼 `9a07bfbd9b3eb136`）。
拆解過程見 [`../re/20-terrain-editor.md`](../re/20-terrain-editor.md)。

## 一、這個編輯器在做什麼

**是一個完整的繪圖程式。** 四個畫筆（`DIRT`／`TREES`／`RIVER`／`CHANNEL`）
直接在地圖上畫，另外兩格是油漆桶（`FILL`，開關）與復原（`UNDO`，動作）；
三個選單（`SYSTEM`／`TERRAIN`／`PARAMETERS`）管城市檔、地形動作與遊戲參數。

本規格涵蓋整個編輯器。分節：

- §二–§六：`TERRAIN` → `Create Random Terrain` 的參數對話框
- §八：主畫面版面（選單列、編輯視窗、工具盤、City Map、狀態列）
- §九：四個畫筆、油漆桶、復原
- §十：三個選單的十七條命令
- §十一：`Game Year`、`Name & Level`、`About`

`internal/sim` 已經有的規則：`GenerateMap` ＋ `TerrainParams`
（`TreeLevel`／`LakeLevel`／`CurveLevel`，`s_gen.c:76-79`）與
`smoothRiver`／`smoothTrees`。編輯器自己那三條在
[`../../internal/sim/editor.go`](../../internal/sim/editor.go)。

## 二、對話框的版面（已確認）

視窗由 `sub_1C010(&win, 0x24, 0x0A)` 建立 —— **36 個字元寬、10 列高**。
之後所有座標都相對於視窗的左上角，單位是字元格：

```
011421  mov ax, 0Ah   ; push  → 10 列
011422  mov ax, 24h   ; push  → 36 欄
011426  lea ax, [bp+var_1C]  ; push ss:&win
01142B  call sub_1C010
```

結構前兩個字組是 `{列, 欄}`：`var_1C` ＝ 頂列、`var_1A` ＝ 左欄。
畫字用的像素座標由它們換算，**一個字元格寬 8 像素**：

```
X 像素 = 左欄 × 8 + 16          (011 4EA：shl 3 後 add 10h)
Y 像素 = (頂列 + 2) × 行高       (011 4FD：var_1C+2 乘 word_596F0)
```

`word_596F0` 是行高（位元組，執行期依顯示模式決定）。

### 標題與兩行標籤

| 元素 | 字串位移 | 位置 |
|---|---|---|
| 視窗標題 `Terrain Creation Parameters` | `ds:0x140` | 由 `sub_1C376` 設在標題列 |
| 第一行標籤 ` Number     Number     River  ` | `ds:0x15C` | X ＝ 上式＋8，Y ＝ 上式＋1 個行高 |
| 第二行標籤 `of Trees   of Lakes  Curviness` | `ds:0x17B` | 同 X，Y 再加 1 個行高 |

畫字的函式是 `sub_19D12(int x像素, int y像素, char far *s)`。

### 六個增減鍵與兩個按鈕（已確認）

建按鈕的函式是 **`sub_17C90(int 欄, int 列, char far *標籤, int 編號)`**
（cdecl 由右往左推，`add sp, 0Ah` ＝ 5 個字組）。

標籤是兩個單字元字串：`ds:0x19A` ＝ `0x11`（CP437 的 `◄`）、
`ds:0x19C` ＝ `0x10`（`►`）。**所以那六個按鈕是三個參數各一組減／增。**

| 參數 | `◄` 欄 | `►` 欄 | 列 | 編號（◄／►）|
|---|---:|---:|---:|---|
| Number of Trees | 左欄＋3 | 左欄＋10 | 頂列＋5 | 0x800 ／ 0x801 |
| Number of Lakes | 左欄＋14 | 左欄＋21 | 頂列＋5 | 0x802 ／ 0x803 |
| River Curviness | 左欄＋25 | 左欄＋32 | 頂列＋5 | 0x804 ／ 0x805 |

| 按鈕 | 標籤 | 欄 | 列 | 編號 |
|---|---|---:|---:|---|
| Go | `   Go   `（`ds:0x19E`）| 左欄＋3 | 頂列＋8 | 0x806 |
| Cancel | ` Cancel `（`ds:0x1A7`）| 左欄＋25 | 頂列＋8 | 0x807 |

兩個標籤都是**八個字元寬、前後補空白**，不是「置中的兩個字」。

### 三個參數的預設值（已確認）

`dseg:0x0B6` 起三個 16 位元值，全部是 **50**：

```
059196  32 00 32 00 32 00      ← 50, 50, 50
```

顯示格式是 `%3d%%%%`（`dseg:0x1B0` 起連續六份，每份 8 位元組）——
**六份是格式字串不是六個標籤**：三個參數各兩份，初次畫用 `0x1B0`／`0x1B8`／`0x1C0`，
按了 `◄`／`►` 之後只重畫那一行、用 `0x1C8`／`0x1D0`／`0x1D8`。

## 三、Go 之後（已確認）

按 `Go` 產生地形、平滑化，然後**回到編輯器**——玩家可以繼續用六個工具改，
不是直接進遊戲。過程中會顯示 `Now terraforming` 與 `Smoothing...`。

`Enter Game Year:`（`dseg:0x127`；`dseg:0x137` 是它那個 `%4d`）與 `Easy`／`Medium`／`Hard`
（far pointer 表在 `dseg:0x116`）**不是** Go 之後的步驟：前者是
`PARAMETERS` → `Game Year`，後者在 `PARAMETERS` → `Name & Level` 的對話框裡
（那一個與遊戲本體的「市名 ＋ 技術等級 ＋ OK」是同一個版面）。
字串在資料段裡相鄰，不代表在流程上相鄰。

## 四、操作（已確認）

`sub_11402` 的訊息迴圈在 `0x11720`。

**滑鼠**：八個控制項的編號 `0x800`–`0x807`。`◄`／`►` 一次加減 **1**，
夾限在 **0–100**（`sub_113E4(0, 值, 100)`）。長按會自動重複：記下按下的時刻，
只要按鍵沒放開、且經過超過 5 個計時單位就再執行一次同一個動作，沒有加速段。

**鍵盤**：`+` 讓焦點往後輪一格（`(focus + 1) % 8`）、`-` 往前（0 折回 7）；
`Enter`／`G`／`g` 等同 Go，`Esc`／`C`／`c` 等同 Cancel。

## 五、百分比就是 `TerrainParams` 的值（已確認）

三個百分比直接是 `TreeLevel`／`LakeLevel`／`CurveLevel`，不需要換算：
產生流程 `sub_10A0A`＋`0x010C58` 與 `s_gen.c:127 GenerateMap()` 逐行對得上，
判空方式（`!= 0` 才做）與消費端的式子都一樣——除了一條。

| 用途 | TERRAIN.EXE | `s_gen.c` |
|---|---|---|
| 湖泊 | `Lim1 = pct / 2` | 相同（`s_gen.c:234`）|
| 河流彎曲 | `r1 = pct + 10`、`r2 = pct + 100` | 相同（`s_gen.c:422-423`）|
| 樹叢擴散 | `dis = Rand(2 × pct + 100) + 50` | 相同（`s_gen.c:279`）|
| **樹叢數量** | **`Amount = 3 × pct`** | `Amount = TreeLevel + 3`（`s_gen.c:301`）|

樹叢數量差三倍（50% ＝ 150 叢 vs 53 叢），實作要走 DOS 那一式：
`TerrainParams.EditorDOS`。詳見 [`../re/20-terrain-editor.md`](../re/20-terrain-editor.md) §七。

原版在 `DoTrees` 之後**又多跑兩次** `SmoothTrees`（共四次）。

## 八、主畫面的版面（已確認）

**編輯器用的是遊戲本體那一套視窗系統，座標完全相同**——
[`ui-layout.md`](ui-layout.md) §二 量到的每一個數字都成立：
選單列 y 0–17、編輯視窗 x 5–579／y 21–324、標題列 y 24–37、
資金帶 y 38–54、地圖區 x 64–575／y 55–310、工具帶 y 311–324、
右邊的視窗 x 240–639／y 21–347。

差別只有五處：

| 元件 | 編輯器 |
|---|---|
| 選單列 | 三個標題，中心 x ＝ **159／347／551** |
| 編輯視窗標題列 | **只印年月**（實測 `Jan 1900`），沒有城市名 |
| 資金／訊息帶 | 原版是空的。remake 借它顯示存讀檔的結果（**自訂**）|
| 工具盤 | 六個 52×24 的文字按鈕，取代庫 2 的美術與需求指標 |
| 右邊的視窗 | 標題 `City Map`，**沒有圖層圖示也沒有色階圖例** |

### 工具盤

```
外框   x 8–63、y 55–210（白 2 像素、內一圈黑）
按鈕   x 11–62（寬 52），第 i 個 y ＝ 59 ＋ 25i，高 24
分隔   每個按鈕之間一列 (85,85,85)
選取   內縮的黃色 2 像素框
```

每一格的底是**對應地物的圖塊平鋪**（空地／樹林／水面／水道），
`FILL` 是灰底藍斜線、`UNDO` 是紅底（沒得復原時鋪紅白棋盤）。
標籤顏色固定：空地黃、樹林白、河流與水道青、填滿與復原黑，
外加一圈描邊。**選取只由黃框表示，不換字色。**

⚠ 中文標籤要**描一圈與字色相反的邊**：原版四個亮字配黑邊，
而填滿與復原是黑字，再描黑邊會整團糊掉。

### 狀態列

編輯視窗底部那一條印**目前畫筆的名稱**（原版實測 `Dirt`／`Trees`），
畫法與遊戲本體的工具帶相同（白底藍字）。

## 九、四個畫筆、油漆桶、復原（已確認）

### 九之一 畫筆

工具描述表（`dseg:0x2B42`，一列 18 位元組）決定寫什麼，
`sub_1EF36` 寫的是 `圖塊 + 旗標`：

| 工具 | 編號 | 寫入地圖的 16 位元字 |
|---|---:|---|
| `DIRT` | 1 | `0x0000` |
| `TREES` | 2 | `0x3025`（WOODS 37 ＋ BURNBIT ＋ BULLBIT）|
| `RIVER` | 3 | `0x0003`（REDGE，**不是** RIVER 2）|
| `CHANNEL` | 4 | `0x0004` |

- **一次一格**（表裡那四列的尺寸欄都是 1）。
- **值一樣就不寫也不記復原**。
- 界外不動作。
- **可以拖曳**（表的 +0x00 是 1），按著不放就一直畫。

### 九之二 油漆桶（開關，一次性）

點工具盤第五格切換；亮著時在地圖上按一下做整片填色，**做完自己熄掉**。

帶由**起點那一格的地物類別**決定，不是由畫筆決定：

| 起點圖塊編號 | 要換掉的範圍 | 起點是這一類就什麼都不做 |
|---|---|---|
| < 2 | [0, 2) | 畫筆是 `DIRT` |
| < 21 | [2, 21) | 畫筆是 `RIVER` 或 `CHANNEL` |
| < 40 | [21, 40) | 畫筆是 `TREES` |
| ≥ 40 | —— | **退化成單格畫筆** |

填色前記一份全圖快照；寫進去的值與畫筆那一組相同。

### 九之三 復原

- 環形緩衝區 **5000 格**，一格 `{x, y, 舊值}`，滿了擠掉最舊的一步。
- **全圖快照最多四份**；第五份進來時最舊的被擠掉，環的尾巴跟著跳過它的標記。
- 會記快照的動作：清除地圖、清除人造物、產生隨機地形、三個平滑、油漆桶。
- 沒得復原時發**第 7 號音效**（工具失敗），工具盤那一格顯示成停用。

## 十、三個選單（已確認）

命令碼 ＝ `(選單編號 << 4) | 列號`，分隔線也佔一個列號。項目順序不能重排。

| 選單 | 列 | 項目 | 動作 |
|---|---:|---|---|
| SYSTEM | 0 | 關於地形編輯器 | 開關於視窗 |
| | 2 | 印表 | **remake 自訂**：存成 PNG |
| | 4 | 開新地圖 | 確認後清空地圖、年份歸零 |
| | 6 | 讀取城市 Ctrl-L | 沿用遊戲本體 |
| | 7 | 以……檔名儲存 | 沿用遊戲本體 |
| | 8 | 儲存城市 Ctrl-S | 沿用遊戲本體 |
| | 10 | 離開 Ctrl-X | **remake 自訂**：確認後回遊戲（原版是離開程式）|
| TERRAIN | 0 | 清除地圖 Ctrl-C | 整張填成空地 |
| | 1 | 清除人造物 | 低十位元 > 37 的格子整個寫 0 |
| | 3 | 產生隨機地形 Ctrl-T | 參數對話框 → `Now terraforming` → 產生 → 回編輯器 |
| | 5 | 平滑樹林 | `SmoothTrees` ×2 |
| | 6 | 平滑河流 | `ResetRiverEdges` ＋ `SmoothRiver` |
| | 7 | 全部平滑 Ctrl-A | **先河後樹** |
| | 9 | 造島 Ctrl-I | **開關**：勾起來之後下一次產生地形才造島 |
| PARAMETERS | 0 | 市名與難度 | 只改市名與難度，**不重造地形** |
| | 1 | 遊戲年份 | 見 §十一 |
| | 3 | 音效 | 開關；打勾表示開著 |

### 清除人造物

```
for x in 0..119, y in 0..99:
    if (Map[x][y] & 0x3FF) > 37: Map[x][y] = 0
```

**連旗標一起清成 0**，不是只換圖塊編號。

### 平滑河流的前置（`ResetRiverEdges`）

`SmoothRiver` 只改寫本來就是 `REDGE` 的格子，所以要先把
**四鄰裡有非水面的水格**打回 `REDGE`：

```
水面 ＝ 圖塊編號在 [2, 20]
邊界那一側的鄰居不檢查（x=0 不看左、x=119 不看右、y=0 不看上、y=99 不看下）
```

⚠ 這一支 Micropolis 沒有，是編輯器獨有的。

## 十一、三個對話框

### 遊戲年份（已確認）

視窗 **18 欄 × 5 列**，標題 `Enter Game Year:`，欄位預填
`sprintf("%4d", CityTime/48 + 1900)`。

```
輸入不是恰好四個字 → 發第 7 號音效，丟掉
CityTime = (年 − 1900) × 48
結果 ≤ 0（年份不大於 1900）→ 丟掉
```

**基準是 1900**，與手冊、劇本簡介一致；遊戲狀態列那個 1849
（`../re/16-dos-oracle.md` §七）是另一回事，不要套過來。

### 市名與難度

原版把遊戲本體那個「市名 ＋ 技術等級 ＋ OK」對話框掛在這一條上。
**只設市名與難度**，不重造地形也不換掉目前這張地圖。

### 關於

原版那一頁是 Maxis 1989 年的職稱表加上當年的地址、電話與傳真。
**remake 只轉錄職稱表**（史料），不把別人的聯絡方式放進會跑起來的程式；
全文轉錄留在 [`../re/20-terrain-editor.md`](../re/20-terrain-editor.md) §十五。

## 十二、進度訊息與確認框

- `Now terraforming` 的視窗是 **20 欄 × 5 列**、`Smoothing...` 是 **16 欄 × 5 列**
  （`sub_1C010` 的參數，已確認）。**絕對位置未解**——只有 36×10 那一個量過，
  其餘用同一條公式外推（`客戶區 = (欄×8−8) × (列×14−8)`，水平置中、
  垂直比中央高 7 像素），等級：**假說**。
- remake 的動作是瞬間完成的，所以進度框固定顯示幾個畫格再收掉。
- **確認框（`sub_1C4B2`）的版面未解**：知道「開新地圖」的標題是 `NEW GAME`、
  「離開」是 `EXIT`，但尺寸與按鈕位置沒有量。remake 先沿用參數對話框的配色
  與 70×20 的按鈕，**標成自訂**。

## 十三、出口

**照原版：編輯器只存檔。** 存成城市檔之後回遊戲，由遊戲的「讀取舊有檔案」
把它讀進來（使用者定案 2026-09-03）。編輯器改的是自己那一張地圖，
動不到玩家正在玩的城市；離開時原本那張地圖原封不動放回去。
