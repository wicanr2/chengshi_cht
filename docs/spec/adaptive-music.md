# 情境式背景音樂規格

**狀態：CONFORMED。日期：2026-08-31。**

這份規格只涵蓋 remake 新增的背景音樂控制。1989 DOS《模擬城市》沒有背景音樂；
本機使用的曲目來自玩家自備的《SimCity 2000 Special Edition》，不是一代原版資產，
也不進公開 `release/`。來源與轉檔證據見
[`../research/sc2000-music-import.md`](../research/sc2000-music-import.md)。

## 一、已確認的產品決策

- 採用**情境式配樂**，排除只按檔名依序輪播。
- `M` 繼續控制音樂開關，`[`／`]` 繼續允許玩家手動換曲。
- 玩家手動換曲後，系統不得立刻搶回選曲控制。
- 音訊裝置、音樂目錄或合適曲目不存在時，遊戲照常執行；背景音樂不是啟動必要條件。
- 公開 `release/` 只提供播放器與合法匯入說明；含 SC2000 OGG 的 `full/` 只能本機保存。

## 二、已證實的事件入口

模擬層已把訊息分類為一般建議、問題、緊急、通知、災難、地震、交通與工具失敗；
`MsgClassDisaster`／`MsgClassQuake` 是目前最穩定的 UI 音樂觸發入口。六種玩家災難為
火災、水災、空難、龍捲風、地震與怪獸，劇本另有空襲及核熔毀排程。

事件的結束條件不完全相同：地震是瞬間修改地圖，水災有 `FloodCnt`，空難、龍捲風與
怪獸由精靈生命週期控制，火災則由地圖上的火焰格持續演算。因此「收到災難訊息」可
證明開始，卻不能單靠訊息消失證明災難已結束。

## 三、曲目事實

- 本機共有 18 首可解碼 OGG，檔名為 `SC2000-10000.ogg` 至 `SC2000-10018.ogg`，
  排除音效用途的 `10017`。
- 長度為 17.9–194.7 秒；短過場與長篇城市曲不能視為可任意互換的同質清單。
- 外部曲目表把 `10004` 對應為〈Disaster Decision〉，但其餘曲目的情緒分類仍需人耳
  驗收；檔名或自動音訊特徵不能代替玩家對曲風的判斷。

## 四、已確認的選曲

1. **已確認：**每種災難固定主題；排除統一危機曲池與按嚴重度分級。
2. **已確認：**災難曲完整播放一次，曲末再從平時曲池選曲；不追蹤模擬層的災難
   結束狀態，也不恢復先前曲目的播放位置。
3. **已確認：**手選曲目期間不做一般情境切換，但災難可立即中斷；災難曲播完後回到
   自動平時曲池。排除「所有自動切換都等手選曲播完」與永久手動模式。

不得用排序索引把任意自備音樂誤認為 SC2000 曲目。

## 五、平時曲池（已確認）

只在曲目自然結束時讀取 `CityClass`，不因人口跨級中途搶歌。`CityClass` 0–3 各自一池，
4（大都會）與 5（巨型都會）共用最高階池；同池兩首輪替，不連續重播同一首。

| `CityClass` | 曲目 |
|---|---|
| 0 村莊 | `10010`〈Virtual Village (Short)〉、`10011`〈Virtual Village〉 |
| 1 小鎮 | `10005`〈Repetition Rendition〉、`10016`〈Repetition Rendition (Ver.B)〉 |
| 2 城市 | `10006`〈Mayor Mombo〉、`10014`〈Chinatown Concerto〉 |
| 3 首府 | `10009`〈Bluesy Berg〉、`10015`〈City Shimmy (Short)〉 |
| 4–5 大都會／巨型都會 | `10001`〈Downtown Dance〉、`10018`〈SimCity Segue〉 |

玩家自備目錄缺少該階段的精確檔名時，從非固定災難曲的可用檔案輪替；若全部曲目都
屬固定災難檔，才退回整份可用清單。分類用不含副檔名的檔名比對，`.ogg`／`.wav` 都可。

## 六、播放優先序（已確認）

```text
災難立即插播 > 玩家手選 > 曲末依 CityClass 自動選曲
```

- 災難採直接切歌，不做未確認的淡入淡出或雙播放器混音。
- 同一災難曲正在播放時，重複訊息不得把曲目從頭重開。
- 不同災難接續發生時，較新的災難可切換到自己的固定主題。
- 玩家手選曲目自然播完後恢復自動；災難插播曲自然播完後也恢復自動。
- `M` 只暫停／恢復目前模式，不改變上述優先序；`-mute` 完全不建立播放器。

## 七、驗收結果

- 純狀態測試涵蓋一般曲池、手選、災難插播、同災難不重啟、不同災難接續與曲末恢復。
- 六種玩家災難、劇本空襲與核熔毀均對應固定曲名；缺檔時不把任意玩家曲目誤分類。
- 正常玩家路徑在 Docker／Xvfb 中以 `Alt-D` 觸發火災，確認切到
  `SC2000-10004.ogg`，解碼器與播放器成功啟動。
- 獨立音訊煙霧測試確認播放器輸出非零音訊；自動切歌測試使用 ALSA null 裝置，兩者分工
  驗證「確實切換」與「確實產生音訊」。技術驗收不冒稱為人耳曲風評鑑。
