## 一、原版是一個視窗系統，不是固定版面

這是與現行 remake 最大的差別，而且是**結構性**的：

| | 原版 DOS 1.10 | 現行 remake |
|---|---|---|
| 選單 | 畫面最上方一條**選單列**，四個下拉選單（按住標題拉開）| 沒有選單列；`Alt-S`／`Alt-D` 開全畫面視窗 |
| 視窗 | **可重疊的浮動視窗**，各有標題列與關閉鈕 | 單一全畫面覆蓋層，一次只開一個 |
| 工具 | 編輯視窗左緣的**圖示盤**，2 欄 × 7 列，24×24 圖示 | 畫面右側的文字清單 |
| 資金與訊息 | 編輯視窗**上緣**一條灰帶：`Funds: $20,000  <訊息>` | 畫面下方狀態列 |
| 目前工具 | 編輯視窗**下緣**一條藍帶：`Residential: $100` | 右側清單反白 ＋ 狀態列一行 |
| 需求指標 | 工具盤下方的小長條圖（R／C／I）| 狀態列中間 |
| 地圖 | 獨立的 `City Form` 視窗，左緣有 10 個圖層圖示 | `Ctrl-M` 開的全畫面視窗，圖層用文字清單 |

City Form（x 241–638）蓋在它右邊三分之二上面。第一次量的時候只量到

⚠ 這些是**這一次開機**的視窗位置。原版的 `Windows → Position`／`Resize`
可以搬動與改大小，所以位置不是常數，是預設值。存檔裡有沒有記視窗位置未解。

## 二之四、查詢面板

**推論等級：已確認**（實測 ＋ 逐項對照）。

操作是**按住 `Q` ＋ 按住左鍵**。參考附表寫的是「`Q`（配合左滑鼠鈕）」，
漏掉的關鍵字是「按住」：**點一下什麼都不會出現**。
前兩次對拍都用點的，一度以為查詢要靠別的操作，還誤試了右鍵——
那其實是「把視窗拉到前面」。實測腳本 `tools/dosbox/act-ui-query4.txt`，
截圖 `workplace/dosbox/uq4-60-query-held.png`。

面板在編輯視窗左下角：**x 8–175、y 208–321**，亮青底、藍字、白框。
一行標題（地物名稱）加五列：

| 列 | 欄位（訊息檔第 15 段）|
|---|---|
| 1 | 密度 |
| 2 | 地價 |
| 3 | 犯罪 |
| 4 | 汙染 |
| 5 | 成長 |

分級邏輯是 `w_tool.c:732 getDensityStr`，二十級。
⚠ 五項的取樣解析度**各不相同**：前四項半解析（`[x>>1][y>>1]`），
成長率八分之一（`[x>>3][y>>3]`）。全部用同一個除法會讓成長率整片相同，
而畫面上看起來完全正常。

**二十個分級用字不在任何 `.PTF` 裡**，硬編碼在執行檔（解壓映像 `0x02548D` 起）：

```
Sparse, Low,    Medium, High     ← 密度
Low,    Medium, High,   High!    ← 地價
Little, Some,   Much,   Severe   ← 犯罪
Little, Some,   Much,   Severe   ← 汙染
Loss,   None,   Some,   Rapid    ← 成長
```

與 Micropolis 的字串資源 202 **用字完全不同**（那邊是 `Low／Medium／High／
Very High`、`Slum／Lower Class／…`、`Safe／Light／Moderate／Dangerous`）。
分級的程式碼兩邊一樣，用字是 DOS 版自己的。本專案照 DOS 的。

⚠ 一開始只抽到十八個字，因為 `tools/dos_exe_strings.py` 的最短長度是 4，
把兩個 `Low` 吃掉了——結果一度以為 DOS 版比 Micropolis 少兩級。
**最短長度是取捨不是安全值。**

對照驗證：原版截圖那一格是 `Sparse／High／Little／Little／None`，
用這張表與分級邏輯算出來的編號是 0／6／8／12／17，逐項對得上。

`Position` 與 `Resize (Edit)`，而且還有 `Close`／`Hide`／`Edit` 三項沒接。

## 四、中文怎麼放進 640×350

原版的字是 8×8 一格。中文最小要 16×16 才讀得清楚，直接換上去會爆版
（`CLAUDE.md` §3.3）。

**擬採用的解法：畫布放大三倍（1920×1050），一個原版字元格 ＝ 24×24 螢幕像素，
一個中文字剛好佔一格。** 效果是：

- 原版美術與版面全部是整數倍放大，不會出現寬窄不一的像素（`rulebook/81`）。
- 英文 `Save City as ...` 佔 16 格，中文「以…檔名儲存」佔 6 格——
  **中文比原文窄**，所以是版面有餘裕，不是爆版。
- 現有的 24×24 點陣字直接用，不必重烘。

⚠ **這一段是提案，不是量出來的事實。** 要先確認原版的字元格真的是 8×8
（量選單列的字高）再定。

## 五、與現行 remake 的落差清單

要做到「操作介面一樣」，下面每一項都要做：

1. **選單列 ＋ 四個下拉選單**（按住標題拉開，滑到項目上放開即選）。
2. **浮動視窗系統**：標題列、關閉鈕、可重疊、`Close`／`Hide`／`Position`／`Resize`。
3. **編輯視窗**：資金／訊息帶在上、圖示工具盤在左、目前工具帶在下、需求指標在工具盤下方。
4. **`City Form` 視窗**：獨立視窗、左緣 10 個圖層圖示。
5. **Graphs／Budget／Evaluation** 也做成浮動視窗。
6. 快速鍵補齊 `Ctrl-E`／`Ctrl-C`／`Ctrl-H`／`Ctrl-P`／`Ctrl-R`。
