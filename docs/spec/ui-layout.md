# 原版 DOS 版面規格 — **READY**（主版面）／草稿（§六的細節）

**日期 2026-08-30。** 一手證據：DOSBox 實跑 DOS 1.10 的截圖，
`tools/dosbox/act-ui-menus.txt` → `workplace/dosbox/ui-*.png`（gitignore）。
數字全部是從截圖量出來的像素，單位是**原版畫面座標**（640×350，EGA 高解析）。

## 一、原版是一個視窗系統，不是固定版面

這是與現行 remake 最大的差別，而且是**結構性**的：

| | 原版 DOS 1.10 | 現行 remake |
|---|---|---|
| 選單 | 畫面最上方一條**選單列**，四個下拉選單（按住標題拉開）| 沒有選單列；`Alt-S`／`Alt-D` 開全畫面視窗 |
| 視窗 | **可重疊的浮動視窗**，各有標題列與關閉鈕 | 單一全畫面覆蓋層，一次只開一個 |
| 工具 | 編輯視窗左緣的**圖示盤**，2 欄 × 7 列，24×24 圖示 | 畫面右側的文字清單 |
| 資金與訊息 | 編輯視窗**上緣**一條灰帶：`Funds: $20,000  <訊息>` | 畫面下方狀態列 |
| 目前工具 | 編輯視窗**下緣**一條藍帶：`Residential: $100` | 右側清單反白 ＋ 狀態列一行 |
| 需求指標 | 工具盤下方的小長條圖（R／C／I）| 狀態列中間 |
| 地圖 | 獨立的 `City Form` 視窗，左緣有 10 個圖層圖示 | `Ctrl-M` 開的全畫面視窗，圖層用文字清單 |

**DISASTERS**（第 20 段）、**WINDOWS**（第 21 段）

```

Graphs         Ctrl-G
Budget         Ctrl-B

Evaluation     Ctrl-U
Close          Ctrl-C
Hide           Ctrl-H
Position       Ctrl-P
Resize (Edit)  Ctrl-R
```

**這解掉了 `docs/spec/controls.md` 的一個未解**：`Ctrl-P`／`Ctrl-R`
不是「視窗位置／調整編輯窗大小」的猜測，就是 WINDOWS 選單自己列的
`Position` 與 `Resize (Edit)`，而且還有 `Close`／`Hide`／`Edit` 三項沒接。

## 四、中文怎麼放進 640×350

原版的字是 8×8 一格。中文最小要 16×16 才讀得清楚，直接換上去會爆版
（`CLAUDE.md` §3.3）。

**擬採用的解法：畫布放大三倍（1920×1050），一個原版字元格 ＝ 24×24 螢幕像素，
一個中文字剛好佔一格。** 效果是：

- 原版美術與版面全部是整數倍放大，不會出現寬窄不一的像素（`rulebook/81`）。
- 英文 `Save City as ...` 佔 16 格，中文「以…檔名儲存」佔 6 格——
  **中文比原文窄**，所以是版面有餘裕，不是爆版。
- 現有的 24×24 點陣字直接用，不必重烘。

⚠ **這一段是提案，不是量出來的事實。** 要先確認原版的字元格真的是 8×8
（量選單列的字高）再定。

## 五、與現行 remake 的落差清單

要做到「操作介面一樣」，下面每一項都要做：

1. **選單列 ＋ 四個下拉選單**（按住標題拉開，滑到項目上放開即選）。
2. **浮動視窗系統**：標題列、關閉鈕、可重疊、`Close`／`Hide`／`Position`／`Resize`。
3. **編輯視窗**：資金／訊息帶在上、圖示工具盤在左、目前工具帶在下、需求指標在工具盤下方。
4. **`City Form` 視窗**：獨立視窗、左緣 10 個圖層圖示。
5. **Graphs／Budget／Evaluation** 也做成浮動視窗。
6. 快速鍵補齊 `Ctrl-E`／`Ctrl-C`／`Ctrl-H`／`Ctrl-P`／`Ctrl-R`。
