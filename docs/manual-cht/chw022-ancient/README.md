# 電腦休閒世界 022《模擬城市－古城風情系列》中文說明書

## 這是什麼

電腦休閒世界 NO.22，MAXIS 正式授權的台港版，360K 六片裝 NT$340，
外盒標 `ALTERNATE ARCHITECTURE Set 1`，對應原版的 **Ancient Asia／Medieval Times／
Wild West** 三個圖形集。外盒角標寫「**內含原遊戲程式**」——六片裡有兩片是原版遊戲，
所以它是一個完整包，不是純資料片。

說明書 65 頁，分三段：

- **第一部份（p.3–47）**：原版《模擬城市》的操作說明。
- **第二部份（p.48–55）**：資料片的安裝、設定與啟動。
- **城市介紹（p.56–64）**：三套古城的世界觀與建築對照圖版。

共 45 張掃描。掃描檔**不進版控**（`.gitignore` 擋掉 `docs/manual-cht/scans/`），
本目錄只保存轉錄的文字。

文字編輯：侯怡如　美術編輯：李志成　美術排版：李惠英

## 兩件值得先知道的事

**一、第一部份與軟體世界珍藏版 29 的譯名幾乎一字不差。** 「悲情城市」「明日之都」「市鑰」
「易如反掌／難易適中／難上加難／比登天還難」「重新建造一新城市」「以……檔名儲存現有城市」
「全自動整地」「持續所有視窗內之活動」，連圖號（圖八 編輯視窗）與八個劇本的說明文都對得上。
兩家是各自向 MAXIS 取得授權的不同代理商，卻用同一份中文稿。這件事本身就是譯名可信度的佐證，
不是重複來源——同一份稿子出現兩次，不能當成兩份獨立證據。

**二、三套古城圖形集的中文名，在這一本之前是本專案自己譯的。** 現在有了 1990 年代的既有譯法：

| 原版圖形集 | 這本說明書怎麼寫 |
|---|---|
| `Ancient Asia` | 古亞圖形／古亞城牆／「獨霸亞洲的 Shogun 家族」（1234 年）|
| `Medieval Times` | 中世紀圖形／繾綣中世紀（1491 年）|
| `Wild West` | 西部圖形／西部拓荒史（1849 年）|
| （原版預設那一套）| **現代圖形** |

各集專屬建築的譯名（摔角場、廟宇、衙門、宮殿、港灣、消防區、水井灌溉系統、水車灌溉系統、
馬術競技場、城堡、警局、賽馬場、警長、金礦區、蒸汽泵系統……）逐項列在
[`p48-64-part2.md`](p48-64-part2.md) 的城市介紹三節，取捨記在
[`../naming-crosswalk.md`](../naming-crosswalk.md)。
