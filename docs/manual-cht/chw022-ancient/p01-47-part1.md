## 一、前言（第一部份）（p.3）

這套由電腦休閒世界正式代理再重新出版的《模擬城市》，總共分為兩大部份，第一部份為原城市的資料，
第二部份則為您介紹古城風情的風采！

## 二、硬體配備（p.3）

1. IBM PC XT/AT 或 100% 相容之機型，主記憶體至少 512K。（使用高解析 EGA 螢幕者則需 640K）。
2. 磁碟機一台（兩台較佳，有硬碟者更好）。
3. 單色（MGA）或彩色（EGA）顯示卡。
4. 鍵盤、搖桿、滑鼠（建議使用滑鼠）。
5. IBM 或 Epson 印表機一台（非必備）。
6. 二片格式化過的空白磁片（一片用做遊戲磁片，另一片儲存你所建造的城市檔）。
7. DOS 3.3 以上版本。

## 三、製作遊戲磁片／載入硬碟（p.4–7）

原始母片無法用來直接進入遊戲，你必須藉母片設定電腦的硬體配備，再載入遊戲磁片或硬碟中，
然後用遊戲磁片或硬碟程式來啟動、進入遊戲。因此，每一片遊戲磁片或硬碟的遊戲程式只能用於
固定的硬體配備，若配備有所更動，則須利用母片重新設定配備，重新製作遊戲磁片或重新載入硬碟。

1. 打開螢幕和主機電源，請務必以 DOS 3.3 以上版本開機。
2. 待 A＞出現後，取出 DOS 磁片，將母片 DISK 1 放入 A 磁碟機中，並關好機門。
3. 在 A＞之下鍵入 Install 按＜Enter＞。

   ※以下的各步驟，請使用 `←→` 鍵選擇你的配備，選好之後按＜Enter＞確定之。
   若選錯了，可按＜ESC＞重新選擇。
4. 首先選擇母片 DISK 1 所在之磁碟機：

   ```
   Install from drive:[*]A:,[ ]B
   ```

   請移動星號選擇 A，按＜Enter＞，在出現的〔N/Y〕：之後鍵入 Y 或 Enter 鍵以確定之，
   或鍵入 N 或＜ESC＞跳回去重選。
5. 其次選擇載入的遊戲磁片或硬碟所在的磁碟機代號：

   ```
   Install to drive:[ ]  A:[ ] B:[ ] C:
   ```

   - a. 載入遊戲磁片：
     - 兩台磁碟機：選擇“B”按 Enter 鍵確定之。
     - 一台磁碟機：選擇“A”按 Enter 鍵確定之。
   - b. 載入硬碟：選擇“C”（或其它硬碟代號），按 Enter 鍵確定之。
6. 接下來出現 `Destination directory->`
   - ◎載入遊戲磁片：請按 Enter 鍵跳過本項。
   - ◎載入硬碟：按 Enter 鍵後，程式會自動在硬碟內開一個名為 Simcity 的子目錄。

   其次請鍵入 Y 或 Enter 鍵確定選擇，或鍵入 N 鍵跳回重選。
7. （選擇載入硬碟的朋友，請跳過此一步驟）

   選擇遊戲磁片的過程可看到以下一段文字：

   ```
   Please insert the destiation disk and press Enter
   ```

   〔原文如此，`destination` 少一個 `n`〕

   - a. 第五步驟選擇“A”的朋友，請將 Disk 1 取出，將一片已格式化（Format）的磁片放入
     A 磁碟機中，關好機門，按 Enter 鍵。
   - b. 第五步驟選擇“B”的朋友，則請將空白磁片放入 B 磁碟機，關好機門，按 Enter 鍵。
8. 選擇螢幕種類：

   （圖說：安裝畫面的引線標註）

   | 引線 | 位置 |
   |---|---|
   | CGA 四色螢幕 | 左 |
   | MGA 單色螢幕 | 左 |
   | EGA 界面卡的 RAM | 左 |
   | 主機的 RAM | 下 |
   | 解析度 | 下 |
   | Tandy 彩色螢幕 | 右 |
   | EGA 彩色螢幕 | 右 |
   | 顯示型態 | 右 |

   使用 EGA 彩色螢幕者，請參考其解析度（Resolution），以及界面卡（EGA RAM）和主機（MAIN RAM）
   記憶容量選擇正確的選項。不過，因為程式本身有偵測能力，你只要隨著星號所在位置，核對一下配備，
   應該錯不了！選好後按 Enter 鍵，再按 Y 或 Enter 鍵確定之。
9. 選擇是否使用搖桿或其他種類：

   - NONE/IGNORE：使用鍵盤或滑鼠。
   - IBM/TANDY TYPE：使用 IBM 或 TANDY 搖桿。
   - COVOX Sound Master：使用 COVOX 音效卡輸出插埠的外接搖桿。

   同前，選定後按兩次 Enter 鍵即可確定之。
10. 選擇音效：

    - None：不要有音效
    - IBM：IBM 內藏喇叭
    - Tandy Digital：Tandy 數位音效
    - COVOX Sound Master：COVOX 音效

    選擇後按兩次 Enter 鍵確定之。
11. 完成以上設定後，你的設定情形都呈列在螢幕左上角由上而下依序為母片所在磁碟機、遊戲磁片
    或硬碟所在的磁碟機、螢幕種類、是否使用搖桿及音效的設定，請再檢查一遍後，在
    `Is this all correct 〔N/Y〕`：之後按 Enter 鍵確定之，或鍵入 N 鍵回去重新設定。
12. 在接下來的載入過程中，製作遊戲磁片的朋友請隨時注意畫面上更換磁片的訊息，將磁片放入
    適當的磁碟機中，再按照指示完成載入的步驟。

    ```
    Source disk 1(disk 2) —— 指母片 Disk 1(disk 2)
    destination disk —— 指遊戲磁片
    ```
13. 當出現 A＞時，即為載入完畢。

◎你的遊戲磁片若是設定為 CGA 或 EGA 的螢幕顯示，則玩者在進行遊戲時須將母片準備好，
以便有時要讀取母片裡的資料。

## 四、啟動遊戲（p.8–9）

- ◎啟動遊戲前，請確定已經先執行過“三、製作遊戲磁片／載入硬碟”的步驟。
- ◎欲使用滑鼠或搖桿者，請在啟動遊戲前先安裝好。使用滑鼠者，須先驅動滑鼠程式。

### A、軟式磁碟機

1. 打開電腦及螢幕電源。
2. 以 DOS 3.3 以上版本開機。
3. 待 A＞出現後，取出 DOS 磁片，將載入完畢的遊戲磁片放入 A 磁碟機中，並關好機門。
4. 在 A＞下鍵入 SIMCITY 按＜Enter＞即可。
5. 接下來的步驟請參考下一章。

### B、硬式磁碟機

1. 打開電腦及螢幕電源。
2. 待 C＞出現後，鍵入 CD SIMCITY 按＜Enter＞，進入此遊戲的子目錄中。
3. 待進入子目錄之後，鍵入 SIMCITY 按 Enter 鍵即可。
4. 接下來的步驟請參考下一章。

### Ⅰ、路標選擇畫面（p.9–14）

啟動遊戲後，畫面出現“模擬城市”（SIMCITY）的路標牌。

（圖說：`SIM CITY` 路標，三塊牌子 `START NEW CITY`／`LOAD A CITY`／`SELECT SCENARIO`）

初玩者先選擇“建造新城市”，因為對一位經驗不足的市長先生來說，選擇治理“悲情城市”
會造成你政治生涯上一個無法磨滅的遺憾！！

當你建造過一些城市，並將它儲存（Save）起來後，你才能選擇“讀取先前儲存的城市檔”。

請利用方向鍵移動游標到任一方框內，按左滑鼠鈕（空白鍵或 Ins 鍵）以進入該功能。
在此先一一介紹各選項：

#### 1. 建造新城市（p.10）

（圖說：`SIMCITY city name:` 對話框，引線標「技術等級」「市名欄」與「簡易／適中／艱難」
分別指向 `Easy`／`Medium`／`Hard`）

本畫面供你為新城市取名，每個新城市有個固定的名字—“HERESUILLE”〔原文如此，
畫面上是 `HERESVILLE`〕，要改名的話，請移動游標到市名欄中按左滑鼠鈕成為輸入狀態，
你可以鍵入 17 個字的名稱，但是存到磁碟中時僅取前 8 個字，輸入後請按 Enter 鍵。

其次選擇等級，初玩者請選擇“簡易”等級，在該項白框中按左滑鼠鈕。在較難的等級裡，
災難的機率提高；市民對稅率比較“過敏”；公產維護費用會逐年增高……等，較不適合初學者來處理。
設定完後，在“OK”處按左滑鼠鈕即可進入遊戲。

#### 2. 讀取先前儲存的城市檔（p.11）

（圖說：`Select filename for SIMCITY load` 視窗，引線標「市民欄」〔原文如此，應為「市名欄」〕
「檔案磁片所在之磁碟機座」「檔名欄」「捲動指標」「取消」「檔案讀取窗」）

在“檔案讀取窗”中，可讀取你先前儲存的城市檔進行遊戲。

- a. 先選擇檔案磁片所在之磁碟機代號。假若你把城市檔存在另一片檔案磁片上，則請先放入
  該磁碟座中，在該字母代號上按左滑鼠鈕（或空白鍵，Ins 鍵）即可。
- b. 其次在檔名欄中會顯示所有你儲存的城市檔。儲存在硬碟的檔案會以目錄檔顯示在代號之後，
  子目錄以括號顯示之，如果看子目錄中的程式，可在該目錄檔名上按左滑鼠鈕即可。若檔案太多
  不能一次顯示可在右側的捲動指標箭號處按鈕即可顯示其他的檔案。
- c. 在市名欄內按鈕，成為輸入狀態，請鍵入欲讀取之城市檔名，按 Enter 鍵，再到“Load”處按鈕，
  即可進入該城市模擬。
- d. 不想在此時讀取城市檔，可在“Cancel”處按鈕即可回到上一個畫面。

### Ⅱ、輸入密碼（p.15）

在進入遊戲後，無論是建造新城市，或是進行先前儲存的城市，畫面上常會出現一小方框，
要求輸入某城市的市名或人口總數。

此時，請拿出附贈的密碼表。方框中的第一個方塊符號代表頁數，請對照密碼表各頁右上角的
方塊符號，找到符合的那一頁。根據方框中的其餘兩個方塊，可以找到該頁中符合的那一頁，
〔原文如此，後一個「頁」應為「列」〕請依照方框中的要求，輸入該項城市的名稱或人口數。

注意：

1. 輸入數字時，不可將逗點一併輸入。
2. 有些市名由兩個以上的字組成，則輸入時，字與字間的空格也需保留。
3. 千萬別輸入錯誤的密碼！！否則程式本身會千方百計地設法破壞你即將進入的城市。
4. 通過密碼測試後，請在其次出現的方框時，按 Enter 鍵，或在“Continue”處按左滑鼠鈕即可繼續。
5. Population 表人口，NAME 表輸入市名。

- c. 利用方向鍵找出一塊你的市區預定地，最好選擇在河流水區附近。找到一塊最佳的市地後，

  市地上，此時游標轉換成方框（隨圖形方塊的種類而有不同大小），移動方框到你預定的工業地上，

- e. 其次選擇商業，住宅圖形，在工廠附近設置，最好以商業區隔開工廠和住宅。注意！！保留一些森林地！

- g. 選擇道路，大略設置一些幹道即可，不必每區四周都設。
- h. 初步完成一個小鎮的樣子之後，按最快速度鍵 $4，使時間開始進行。
  這時你可以觀察小鎮的發展：住宅區開始出現零散戶，工廠也初步有小規模形成，漸漸地發展，
  隨著右上角時間一個月一個月地過去，你的小鎮建設起來了！！
- i. 現在把時間放慢，或甚至暫停，好好地把“操作手冊”看一遍吧！相信以上的引導，應該使你
  對你的工作奠定了無比的信心才對，祝你早日完成“大都會區”的心願！

## 五、控制方法（p.19–23）

### Ⅱ、功能選單（Options）（p.27–28）

以下的功能設定會隨著你儲存城市時存入。當任一項指令啟用時，則其左側會有一個小箭頭符號出現。

1. **全自動整地（Auto-Bulldoze）**：可使你直接在樹林、河、海岸線設置道路、房宅等，
   而無須先軋平整地，但是仍然會將整地的費用合併計入。
2. **自動編列預算（Auto-Budget）**：使用你的預算保持相同的編列百分比 Funding Level，
   而無須每年都要請示你的允許通過。如果資金不足無法和預算平衡時，則資金會優先撥給運輸系統
   （Trans System），其次順序為消防隊（Fire Department）、警察局（Police）。
3. **自動前往災難現場（Auto-Goto）**：災難發生時，可以將畫面立即切換成災難或事件的發生地點。
   如果此項功能不啟用，則有災難發生時，編輯窗的訊息欄內會傳來消息，此時，你必須按左滑鼠鈕或
   Tab 鍵切換至災區現場，再按一次 Tab 鍵則又可切換回原來的地區。
4. **音效（Sound）**：啟開或關閉音效（Sound On/Sound Off），音效關閉後，模擬速度會稍微加快。
5. **模擬速度（Speed）**：選擇本項則有副選單出現，選擇“Fastest”則使遊戲的進行速度最快，
   “Fast”其次，“Average”為一般速度，“Solw”較慢〔原文如此，應為 Slow〕，
   “Pause”則使遊戲時間停止，此時你可以用來建設或分區，但是你的城市將不會有任何成長開發。

   電腦型為 8088，執行速度 4.77MHz（XT 相容型）的朋友，可將速度定為 Fastest。
6. **持續所有視窗內之活動（Animate All）**：啟用此項功能，當編輯視窗被其他視窗被其他視窗
   重疊在上時則編輯視窗內之時間活動繼續進行，時間會照常更新。當關閉此功能，則模擬時間會隨
   其他視窗出現而停止。這項功能不會隨城市的儲存而被設定住。
7. **加快市區景物活動（Friguent Animation）**〔原文如此，應為 Frequent〕：此項功能在設定
   遊戲進行中之固定音效的出現頻率。並使模擬內容生動化。例如車子的流動、煙囪冒煙的步頻率會加快。

#### C、預算視窗（Budget Window）（p.36–38）

（圖說：預算視窗，左側引線「稅率／稅收／維護需求額／交通／警局／消防隊」，
右側引線「實際撥給金額（＝支付百分比×維護需求額）／編列（支付）百分比／現金流量／
＋年底現餘資金／＝明年初結餘資金」；畫面欄位為 `Amount Requested`、`Amount Allocated`、
`Funding Level`，列為 `Trans`、`Police`、`Fire`）

從新建的城市第一年收到稅之後，每年的 12 月底預算視窗會出現一次（除非你設定了自動編列功能
（Auto-Budget），請你設定明年度運輸、警察局和消防隊之預算百分比。並設定適當的稅率（Tax Rate）。

如果你啟用了自動編列預算功能（Auto-Budget），則預算水平將採用你上一次設定的百分比，
或是全額（100%）編列。倘若你資金不足以支付預算時，則錢將優先撥給運輸部門，其次以為消防、
再次為警察部門。

你可以移動游標到百分比左右兩側的 `▲` `▼` 符號處，按左滑鼠鈕（空白鍵或 Ins 鍵）便可提高或
降低百分比。調整完後，在最底下的“GO With these figures”處按左滑鼠鈕即可結束本視窗。

使用＋－鍵可幫助你快速移動箭頭以選擇想更改的地方。左滑鼠鈕（空白鍵或 Ins 鍵）按一次可改變
一個百分比（1%），右滑鼠鍵或 Delete 鍵可一次可改變 10%。

◎注意每當你重新讀取某一城市時，預算視窗內的預算金額皆為 0，直到次年的一月為止。
頭一年為寬減時間。但所有部門則視為已完全支付預算了。

- （1）**稅率（Tax Rate）**：
  - ＊你能設定的最高稅率為 20%。你能設定的最低稅率為 0%。
  - ＊快速成長時的適用稅率較低為 5 至 7%。緩慢成長而不萎縮，適用高稅率 8 至 9%。
  - ＊每一區收得之稅金，依下列公式計算而得：

    ```
    稅金＝人口數×地價×稅率×比例常數
    （比例常數視遊戲的困難程度而定）
    ```
- （2）**支付百分比（Funding Level）**：你所設置的警察局或消防隊，則每年需支付的維護費用為
  每座 $100。除非你設置了，否則無需支付。但不能支付超過 100%，本市的警察局長和消防隊長都
  十分廉潔，不會收你多餘的錢的。

  當撥給金額（Amount Allocated）低於需求額（Amount Requested）時，則該部門的辦事效率會降低。

  交通維護費用稍低於 100% 時，會引起運輸系統緩慢退化。支付 75～90% 會使道路或鐵軌有明顯的損壞，
  多段無法使用。低於 75% 會造成嚴重惡化。
- （3）**現金流量（Cash Flow）**：

  ```
  現金流量＝稅收（Taxes）－總支付金額
  ```

  當支付金額高於稅收時，會有負的現金流量。但是本模擬城市與真實城市不同處在於：
  它不容許有預算赤字！！

2. **統計數據（Statistics）**：

每年的預算時間一到，這些數據都會顯示出：

- a. **人口總數（Population）**
- b. **人口遷出入數（Net Migration）**：負值代表遷出，表示你的城市有問題，該解決了！
- c. **市有財產總額（Assessed Value）**：為道路、鐵路、發電廠、警局等總價值，
  但不包括商業、工業及住宅區。
- d. **本市類別（Category）**：由人口數來定義

  | 原文 | 中文 | 人口 |
  |---|---|---|
  | Village | 村莊 | 0 ～ 1,999 |
  | Town | 小鎮 | 2,000 ～ 9,999 |
  | City | 城市 | 10,000 ～ 49,999 |
  | Capital | 首都 | 50,000 ～ 99,999 |
  | Metropolis | 都會區 | 100,000 ～ 499,999 |
  | Megalopolis | 大都會區 | 5000,000 以上〔原文如此，應為 500,000〕|

- e. **遊戲等級（Game level）**：有簡單，中等，困難三種。
- f. **整體成績（Overall City Score）**：綜合以上各係數所得的本市成績（請參考都市動力表）：

## p.47

主要因素：犯罪率、污染、居住費用、稅、交通、失業問題、防火、停電區、都市成長等。

次要因素：體育館、海港、機場之需求程度（並非已建者）、道路預算、警局和消防隊預算等。

由目前累計成績（Current Score）表之，每年結算時，會將去年的累計成績加上今年的年度成績
（annual change）即為整體成績。年度成績為負值時，表示都市的發展萎縮了。
