1. 主記憶體至少 512K 之 IBM PC XT/AT 或 100% 相容之機型。（使用高解析度 EGA/VGA ＆ MCGA 螢幕者，則需 640K 記憶體）。
2. 一台或 2 台磁碟機（最好有硬碟）。
3. 單色及彩色顯示卡（EGA、VGA、）。〔原文如此，句中頓號後空〕
4. 鍵盤、搖桿、滑鼠（建議使用滑鼠）。
5. COVOX 音效卡（非必備）。
6. IBM 或 Epson 印表機一台（非必備）。
7. MS 或 PC-DOS 2.0 以上版本。（不適用 DOS 5.0）

> 第 7 條的「不適用 DOS 5.0」是本書獨有的警告，軟體世界珍藏版 29 與電腦休閒世界 024 都沒有。

## 三、製作遊戲磁片／載入硬碟（p.49–52）

> 我們建議你最好製作遊戲的備份磁片，以 COPY 好的備份磁片來進行遊戲，並妥善保存遊戲母片
> 以免因不當使用而損壞。

遊戲不得以原始母片進行，須配合原始的《模擬城市》遊戲磁片，再利用《模擬城市》的圖形資料磁片
來重新設定配備，製作新的遊戲磁片或重新載入硬碟。也就是說，在載入資料磁片前，必須已先載入
原始的遊戲磁片。

### A、載入硬碟

須預留給每個新的繪圖程式，110K 的硬碟空間（總共 330K）。

1. 開機後，先確定你已載入原始的《模擬城市》遊戲。
2. 放進 Simcity 圖形磁片（Graphics）的 #1:Install 磁片，並鍵入 Install＜Enter＞。
3. 出現準備 Install 前的訊息，按＜Enter＞跳到此畫面。
   （圖說：`SimCity Graphics Install Program Set #1`，引線標「選擇從 A 磁碟機 Install」「選擇從 B 磁碟機 Install」）
4. 選畢後按＜Enter＞，出現畫面：
   （圖說：`Do you wish to install to a HARD DISK or to FLOPPY DISKS?`，引線標「選擇 Install 至軟碟」「選擇 Install 至硬碟」）
5. 選擇硬碟，按＜Enter＞鍵後，電腦會自動找尋到 C:\Simcity 子目錄中，
   （注意：如果你仍尚未載入原始遊戲，按＜Esc＞回去先載入吧！）。
6. 按＜Enter＞跳至此畫面，選擇 3 種圖形都設定的程式＜Enter＞。

   （圖說：`SimCity Graphics Install Program Set #1`，四條引線）

   | 畫面選項 | 圖說 |
   |---|---|
   | `Ancient Asia` | 設定古亞圖形 |
   | `Medieval Times` | 設定中世紀圖形 |
   | `Wild West` | 設定西部圖形 |
   | （三者全選）| 設定以上三種圖形 |

   > 畫面上的英文原文是 `Note: Each of the new alternate architectures will require up to 110k of
   > free disk space. If you have the space, we recommend you install them all.`
7. O.K. 手續完畢，開始 Install，請依畫面顯示的指示訊息，依序放入所需磁片即可。
8. Install 完畢後會出現原始《模擬城市》所設定的使用資料，若欲更改，按＜Enter＞回到
   C:\Simcity 下，鍵入 Settings＜Enter＞即可重新去設定。

### B、製作遊戲磁片—（軟體使用者）〔原文如此，應為「軟碟使用者」〕

使用軟碟者，需製作磁片才能進行遊戲，手續挺麻煩的，所以要小心進行。首先，準備好所需的磁片：
原始《模擬城市》的 2 張磁片（Orginial Simcity Sisks）〔原文如此〕；《模擬城市》的四張圖形片
（Simcity Graphics disks）；你原先已製作載入好的原始《模擬城市》之遊戲磁片，並請貼上
play disk 標籤以標示（注意，若你尚未製作原始《模擬城市》的遊戲片，請一定要先去製作好）；
2 張已格式化的空白磁片，並分別貼上 Classic Graphics disk 及 Scenario Disk 的標籤以標示。

1. 再一次確定準備好的磁片，2 張 Origial Simcity disks，4 張 Simcity Graphics disks（圖形片）,
   Simcity play disk（遊戲戲片）及 2 張已格化的空白磁片。〔原文如此，錯字與標點照抄〕
2. Install 的步驟同硬碟，先放入繪圖篇（Graphics）的 #1:Install 磁片鍵入 Install＜Enter＞，
   （參考載入硬碟步驟 2,3,4）。
3. 接著按所指示訊息進行，請務必看清楚訊息，放入所需磁片。
4. 你亦可利用 Play disk 來重新 Setting 使用資料的程式。

## 四、重新設定程式資料（The Settings Program）（p.52–53）

你可以更改原始《模擬城市》載入時所使用的程式資料，重新設定新的使用資料。

### A、硬碟使用者

1. 進入子目錄 C:\Simcity＞下，鍵入 Settings＜Enter＞後，會出畫面指示你可進行更改的項目，按＜Enter＞繼續。
2. 選擇在硬碟更改設定。
3. 按＜Enter＞跳過確定子目錄的訊息畫面。
4. 手續完畢，出現可進行設定的資料畫面，用方向鍵選擇，並按＜Enter＞進入更改和確定。

   （圖說：`SimCity Graphics Settings Program` 兩張截圖）

   上圖引線：

   | 引線 | 內容 |
   |---|---|
   | 控制方式（是否使用搖桿）| `Your control device (joystick or mouse)` |
   | 顯示型態 | `Your video mode`（包括 EGA、VGA、CGA…等）|
   | 音效配備 | `Your sound type`（IBM、TANDY、COVOX）|

   下圖引線：

   | 引線 | 畫面選項 |
   |---|---|
   | 更改控制型式 | `Change Control Device` |
   | 存取並結束 | `Change Sound Type` 之下的存檔項 |
   | 更改顯示型態 | `Change Video Mode` |
   | 更改音效配備 | `Change Sound Type` |
5. 再按＜Enter＞即完成；你可隨時重新再去更改之。

### B、軟碟使用者

1. 開機後，取出 DOS 片，放入 Simcity 的遊戲磁片（play disk），在 A＞下鍵入 Settings。
2. 選擇在軟碟（floppy disk）設定。（其餘程序請參照硬碟 Settings 步驟即可）

## 五、啟動遊戲（p.54–55）

### A、硬碟使用者

1. 按一般程序開機。
2. 在 C＞出現後，鍵入 CD SIMCITY＜Enter＞。
3. 待進入子目錄後，再鍵入 SIMCITY＜Enter＞即可。
4. 操作方法與原始《模擬城市》遊戲完全相同。待輸入密碼進入主畫面後，進入訊息欄的 SYSTEM，
   選擇 Londing graphics 後〔原文如此，應為 Loading〕，你便有四種不同年代的城市圖形可以選擇；
   選擇完後，按下右上角的 LOAD 確定，便出現所需圖形。

（圖說：遊戲中的 `SELECT NEW GRAPHIC SET` 對話框，四條引線）

| 引線 | 對應 |
|---|---|
| 古亞圖形 | `Ancient Asia` |
| 西部圖形 | `Wild West` |
| 現代圖形 | 原版的預設圖形集 |
| 中世紀圖形 | `Medieval Times` |

> **「現代圖形」是本書給原版預設圖形集的名字。** 遊戲裡四個選項並列，前三個是資料片，
> 第四個是原版自己那一套。

### B、軟碟使用者

1. 利用 DOS 片開機（使用滑鼠者，確定滑鼠之驅動程式已載入記憶體）。
2. 將遊戲磁片（play disk）放入 A 槽，在 A＞下鍵入 Simcity＜Enter＞即可進入遊戲。
3. 光是利用遊戲磁片並不能進行遊戲，所以隨時會用到其他磁片；請看清楚畫面的訊息，
   放入所指定的磁片以進行遊戲。
4. 遊戲磁片只能以現代城市的圖形來進行遊戲，若要選擇其他城市的圖形，同樣也是進入 SYSTEM 下的
   Loading Graphics 去選擇；不過，切記在選擇 Loading Graphics 步驟前，放入你所需的城市圖形磁片
   才能 Load 出圖形來。
5. 操控方法與原始《模擬城市》完全一樣。

## 六、城市介紹

### 獨霸亞洲的 Shogun 家族（p.56–58）

1234 年，你是有權有勢 Samurai 家族的後裔，而現在你要出門獨立建造另一個屬於你自己的大城，
橫跨整個亞洲的 Shogun 皇帝。

**區域**

設計建造房子時要兼顧美學和發展喔！住戶居住地的大小和密度是由小住戶擴大到大型四合院式住邸；
商業區有獨立的商店和大型市場，在大型市場可賣東西或進行交易；工業區主要由農地構成，
城市的工業收入有些是來自漁業。

建設港灣可以提高工業的成長；築宮殿可以提高商業收入並幫助村莊發展。

**給水及電力系統**

村落必須導引灌溉系統以供居民用水及發電用，有水井（較便宜）及水車系統（代替現代的發電廠）。

**交通型態**

在這模擬的古城，必須用走的或騎馬，不過是走在泥土路上。也可以舖磚塊路讓黃包車通行，
在磚塊路行走速度較快（類似鐵路，）所以可以幫忙疏解繁密的交通。

**犯罪率**

雖然有酷嚴的法律和刑罰，犯罪行為仍是很猖獗。從食物到貴重的珠寶，小偷每樣東西都偷。
還會有一些野心勃勃的市民暗中策劃陰險的計策和從事破壞的行為來挑戰你的勢力。

**污染**

污染主要來是人類和動物不衛生的經營和習慣。〔原文如此〕

**災害**

災害除了地震、水災（Tsunamis）、火災和怪獸侵襲外，還增加了中國的龍捲風、颱風和黑死病。

**其他**

- 在築宮殿時，天空會出現一條飛龍和一個盒形的巨大風箏。
- 用犁砍伐森林；也可以用來挖掉舊建地以重建。
- 休閒時，可以去 Sumo 競技場看摔角比賽。

### 繾綣中世紀（p.59–61）

在 1491 的中世紀，你是這片文化沙漠的先驅者、主宰者、建造者，所以必須很努力來開拓這片疆土，
好好追求你的名望，美好的未來及成就吧！

**區域**

你是這中古世紀的國王，可得好好為你的國民建造一座最棒的城鎮喔！居住地的發展從小農舍擴展到
大型城堡；商區從小型商店擴大到大型的市場集散地；工業區的大小範圍同商區及住宅區，主要有紡織廠、
小麥磨坊（以風車為動力）；建設港灣可提高工業的成長。築城堡（Castle）可以幫助鄉村的商業發展。

**給水及電力系統**

當然，這個時代是沒有電可供給發電的，你仍須導引灌溉系統以給水予住民使用，發電及給水能源來自
水井（較便宜）及水車系統。

**交通型態**

交通主要仍是以在泥土路上行走及騎馬進行；交通太繁雜時，可以舖石板路來疏解，讓運馬車行走。

**犯罪率**

罪犯到處橫行，有扒手、小偷、過路劫財者，甚至還有搶劫、謀殺旅客的盜賊，夠傷腦筋的吧！！

**污染**

污染是因無知的農夫們，清理馬棚，而沒有好好處理所造成的。

**災害**

災害除了地震、水災、火災、颶風和怪獸的侵害外，還增加了龍捲風和黑死病。

- 救火方式是以水桶汲水，消防隊員是由村民們自己組成。

### 西部拓荒史（p.62–64）

1849 年，你「一馬當先」到蠻荒的西部挖金尋寶；可是 12 年下來的辛苦挖掘，讓你又飢又渴，
累了還只能睡在一望無際的荒野中，你實在需要找個城鎮住並且還須要有礦工人口來幫你才行，
所以現在讓你來當這狂野西部的郡長（去建造一些旅館啦、酒店和商店……等好好享受一番吧！），
試著開發出一座真的城鎮來。

**區域**

儘量保持城鎮邊鏡的和平；將粗暴的礦工跟孔武的拓荒者隔離，農夫和牧場主人也要隔離，
然後設定居民吃喝住及工作的地區。〔「邊鏡」原文如此，應為「邊境」〕
城鎮的發展密度從小農舍到大工寮再擴大到大型牧場或農場住地。商業區可購物和提供服務就業機會，
也是由獨立的小型商店擴展到大型商店。工業區主要由牧場形成，大小與商業區和住宅區相同。
建設海港可提高工業的交易和成長。挖掘金礦可以增加村落商業的成長。

**給水及電力系統**

這時代已有進步的蒸汽發電設施（較昂貴）及水車系統，好好享受文明進步的產物吧！

**交通型態**

城鎮中主要的交通型態是走路及騎馬。要趕時間的話可以舖設鐵路，乘坐蒸氣火車；鐵路可以幫助疏解交通。

**犯罪率**

警長必須制裁的有偷牛賊、逃犯、偷金礦的盜賊及到處都有的混混。

**污染**

污染主要是來自屠仔場及牧場的垃圾。（大概是屍骨及排泄物吧！！）

**災害**

這個時代的災情除了地震、水災、火災和颶風外，還增加了墜毀的熱氣球、巨大的食人滾草及水源的污染。

- 消防器材是一輛載著大型貯水槽的水車。

## 轉錄註記

- `Orginial Simcity Sisks`（p.51）、`Origial Simcity disks`（p.52）、`Londing graphics`（p.54）
  都是原文的拼字錯誤，不代為訂正。
- **三套的水／電設施標示是成對的**：`水井灌溉系統` 對應原版的火力發電廠，
  第二座則各集不同（古亞與中世紀是 `水車灌溉系統`，西部是 `蒸汽泵系統`）。
  正文把兩座統稱「灌溉系統」，是因為這三個時代都沒有電——說明書 p.60 明講
  「這個時代是沒有電可供給發電的」。
- **一代沒有自來水系統。** 這裡的「給水」是資料片替換掉發電廠美術後的說法，
