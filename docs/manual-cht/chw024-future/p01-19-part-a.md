農業時代—工業時代—電子時代—資訊時代—太空時代！人類史的發展不過如此？！想到更遙遠的
未來去探險觀光呢？！《模擬城市》繼美得冒泡的「古城系列」後，再推出強打資料片—「回到未來」

### Ⅱ、軟體及硬體配備（p.3–4）

1. 主記憶體至少 512K 之 IBM PC XT/AT 或 100% 相容之機型。（使用高解析度 EGA/VGA ＆ MCGA 螢幕者，則需 640K 記憶體）
2. 一台或二台磁碟機（最好有硬碟）。
3. 單色或彩色顯示系統（Hercules、EGA、VGA、CGA、Tandy）。
4. 鍵盤、搖桿或滑鼠（建議使用滑鼠）。
5. COVOX 音效卡（非必備）。
6. IBM 或 Epson 印表機一台（非必備）。
7. MS 或 PC-DOS 2.0 以上版本。

> 我們建議你最好製作遊戲的備份磁片，以 COPY 好的磁片來進行遊戲，並妥善保存遊戲母片
> 以免因不當使用而損壞。

### Ⅲ、製作遊戲磁片／載入硬碟（p.4–7）

遊戲不得以原始母片進行，須配合原始的《模擬城市》遊戲磁片，再利用《模擬城市》的圖形
資料磁片來重新設定配備，製作新的遊戲磁片或重新載入硬碟。也就是說，在載入圖形磁片前，
必須已先載入城市原始的遊戲磁片。

#### A、載入硬碟

須預留給每個新的繪圖程式 110K 的硬碟空間（總共 330K）。

1. 開機後，先確定你已載入原始的《模擬城市》遊戲。
2. 放進 SimCity 圖形磁片（Graphics）的 #1:Install 磁片，並鍵入 Install 後，按 Enter。
3. 出現準備 Install 前的訊息，按 Enter 鍵跳至選擇的畫面。移動反白區選擇 Install 片所在之磁碟機：

   ```
   FROM which drive are you installing?
   DRIVE A：   ← 選擇從 A 磁碟機 Install
   DRIVE B：   ← 選擇從 B 磁碟機 Install
   ```
4. 選畢後按 Enter 鍵，從下一個畫面選擇要載入到硬碟中或軟碟：

   ```
   Do you wish to install to a HARD DISK or to FLOPPY DISKS?
   HARD DISK      ← 選擇 Install 至硬碟
   FLOPPY DISKS   ← 選擇 Install 至軟碟
   ```
5. 選擇硬碟，按 Enter 鍵，電腦會自動找尋到 C:\SIMCITY 子目錄中。
   （注意：如果你仍尚未載入原始遊戲，按 Esc 回去先載入吧！）
6. 按 Enter 跳至圖形設定畫面，利用反白塊選擇所需設定的圖形。
   （假如你有足夠的硬碟空間，我們建議您選擇三種圖形都設定）

   | 選項 | 圖說 |
   |---|---|
   | `Install FUTURE U.S.A.` | 設定美國圖形 |
   | `Install FUTURE EUROPE` | 設定歐洲圖形 |
   | `Install MOON COLONY` | 設定月球圖形 |
   | `Install THREE ALL` | 三種圖形都設定 |
7. O.K. 手續完畢，開始 Install，請依畫面顯示的指示訊息，依序放入所需磁片即可。
8. Install 完畢後會出現原始《模擬城市》所設定的使用資料，若欲更改，按 Enter 鍵回到
   C:\Simcity＞下，鍵下 Settings，按 Enter 鍵即可重新去設定。

#### B、製作遊戲磁片—（軟碟使用者）

使用軟碟者，需重新製作磁片才能進行遊戲，手續挺麻煩的，所以要小心進行。首先，準備好
所需的磁片：原始《模擬城市》的二張磁片（Orginial SimCity disks）〔原文如此〕；
《模擬城市》的四張圖形片（Simcity Graphics disks）；你原先已製作載入好的原始《模擬城市》
之遊戲磁片，並請貼上 Play disk 標籤以標示（注意，若你尚未製作原始《模擬城市》的遊戲片，
請一定要先去製作好）；二張已格式化的空白磁片，並分別貼上 Classic Graphics disk 及
Scenario disk 的標籤以標示。

1. 再一次確定準備好的磁片，二張 Origial Simcity disks〔原文如此〕、四張 Simcity Graphics
   disks、Simcity play disk 及二張空白磁片（標示 Classic Graphics disk 及 Scenario disk），共九張喔！
2. Install 的步驟同硬碟，先放入繪圖篇（Graphics）的 #1：Install 磁片，鍵入 Install，
   按 Enter 鍵。（參考載入硬碟步驟 2,3,4）。
3. 接著按所指示訊息進行，**請務必看清楚訊息，放入所需磁片。**
4. 你亦可利用 Play disk 來重新 Setting 使用資料的程式。

### Ⅳ、重新設定程式資料（The Settings Program）（p.7–8）

你可以更改原始《模擬城市》載入時所使用的程式資料，重新設定新的使用資料。

#### A、硬碟使用者

1. 進入子目錄 C:\Simcity＞下鍵入 Settings 按 Enter 鍵後，會出畫面指示你可進行更改的項目，按 Enter 鍵繼續。
2. 選擇在硬碟更改設定。
3. 按 Enter 鍵跳過確定子目錄的訊息畫面。
4. 手續完畢，出現可進行設定的資料畫面，用方向鍵選擇，並按 Enter 鍵進入更改和確定。

   （圖說：`SimCity Graphics Settings Program` 畫面，引線標「選擇更改顯示型態」×3
   與「存取並結束設定」。原文四條引線的文字重複，是排版錯誤——對照電腦休閒世界 022
   的同一張圖，四條應為「更改顯示型態」「更改控制型式」「更改音效配備」「存取並結束」。）
5. 更改完後，便可使用新設定的資料。

#### B、軟碟使用者

1. 開機後，取出 DOS 片，放入 Simcity 的遊戲磁片（Play disk），在 A＞下鍵入 Settings。
2. 選擇在軟碟（Floppy disk）設定。（其餘程序請參照硬碟 Settings 步驟即可。）

### Ⅴ、啟動遊戲（p.8–10）

#### A、硬碟使用者

1. 按一般程序開機。
2. 在 C＞出現後，鍵入 CD SIMCITY 按 Enter 鍵。
3. 待進入子目錄後，再鍵入 Simcity 按 Enter 鍵即可。
4. 操控方法與原始《模擬城市》遊戲完全相同。待輸入密碼並進入主畫面後，進入訊息欄的
   SYSTEM，選擇 Loading graphics 後，你便有四種不同年代的城市圖形可以選擇
   （**若曾載入古城系列，則有 7 種城市圖形**）；選擇完後，按下右上角 LOAD 確定，便出現所需圖形。

#### B、軟碟使用者

1. 利用 DOS 片開機（使用滑鼠者，確定滑鼠之驅動程式已載入記憶體）。
2. 將遊戲磁片（Play disk）放入 A 槽，在 A＞下鍵入 Simcity 按 Enter 鍵即可進入遊戲。
3. 光是利用遊戲磁片並不能進行遊戲，所以隨時會用到其他磁片；請看清楚畫面的訊息，
   放入所指定的磁片以進行遊戲。
4. 遊戲磁片只能以現代城市的圖形來進行遊戲，若要選擇其他城市的圖形，同樣也是進入
   SYSTEM 下的 Loading Graphics 去選擇。**不過，切記在選擇 Loading Graphics 步驟前，
   放入你所需的城市圖形磁片，才能 Load 出圖形來。**
5. 操控方法與原始《模擬城市》完全一樣。

### Ⅵ、城市風情（p.10–19）

#### 生在美國（p.10–12）

由於人口幾乎已快到爆炸的地步了，你必須在 2055 年的今天，好好重建新的城市並控制其
人口的成長，期待你在新紀元的成就啦！

**區域**

60 年後的今天，「情勢」並沒有改變，但所有的「結構」可都不同了；摩登的建築物，
超水準、高科技的生活型態、品質，商業和工業突飛猛進的發展，更是超乎你的想像。住宅區的
範圍從單戶住家發展到大型都會區；商業區可購買貨品和提供服務，範圍從小型商店擴展到大型
購物中心；工業區則有大型的研究發展中心，高科技的設計和生產工廠。興建水翼船港會增加
工業的成長和貿易發展；建造機場／太空站的話，則可大大提高商業成長率喔！

**能源**

這時代，已完完全全沒有落伍的煤燃料了，經濟能源太陽能及風力，也還沒有特別迅速和有效率的
發展來應付，但有兩種發電設施可選擇—核能發電廠及核子融爐電廠，除了它們的商業價值和能源外，
也要注意一下其所帶來的污染和危險。

**交通**

這城市的交通型態，全由電腦控制，人民的交通往來和旅行都乘坐這種應用低氣壓和低摩擦力來建成的
高速地下鐵；交通密度過於擁擠時，可以築更快速的磁軌鐵路來幫助疏通；盡情享受這些高科技的產物吧！

**犯罪率和污染**

21 世紀的今天，犯罪並沒有消失，而且犯罪技巧更高了，真傷腦筋！竊盜機密資料變成最「熱門」的
犯罪行為（因為這是賺最多錢的職業），這些智慧犯更滲透進政府及銀行的電腦系統哩！當然了，
除了抓那些智慧犯，可別忘了還有小偷、凶手、吸毒者等著你去處理呢！

污染狀況大部份還是由工業區產生。

**災害**

這世紀會出現的災害有：地震、水災、火災、颶風、怪獸、墜機……等。

**其他**

- 機場兼具太空站的功能，可運送一些生活必需品或工具到各太空站及月球殖民地去。
- 這時挖土機被一種新發明的大型放射性分解武器取代，夠帥的吧！
- 體育館有超級機器人的競賽，融合了足球和拳擊的技巧，動作迅速又猛烈，有空去瞧瞧，見識一下！

#### 橫掃歐陸（p.12–14）

2155 年，一向有保護文化資產有術美名的歐洲，不禁也因人口的膨脹，開始為經濟及政治問題
擔心起來，即使成立了經濟聯盟，爭辯的情形仍不斷，科技的進步所帶來的弊病，就待您來解決啦！

**地域**

可別把傳統都拋開了，你仍得像以前一樣好好計劃你的城市哩！住宅區仍是由單戶住家擴展到
高密度的公寓及大都會，還有一些由很多家庭組成的自治區；商業區有各種不同的小商店、辦公室、
咖啡廳，一直擴展到大型百貨商店及雄偉的辦公大樓等；工業區的研究中心和製造工廠的生產運作，
對整個歐洲的生活型態挺有影響的。

建設港灣可增加工業區的成長；興建機場／太空站可提高商業區的發展。

**能源**

煤、太陽能、風力，仍是無法應用的能源，100 年後的今天，你只有核能發電廠及核子融爐電廠
可選擇；不過以它們的價值而言，算是很不錯的！

**交通型態**

與美國時期大同小異，完全電腦自動化的交通設備，有應用摩擦力原理建設的地下鐵道及較高速的
單軌鐵路系統。

**犯罪率和污染**

竊罪並沒有因文化及科學的進步而消失；Metropol（警防部）要小心間諜集團的侵入，藝術品被竊
也常發生，吸毒者、刺殺、謀殺案的發生仍很頻繁。

雖然嚴格地對空氣及水源污染問題制定了嚴格的法律來管制，但卻仍無法抑制工廠帶來的污染；
人類根本脫離不了生活在污染的環境之中，然而，人類應就是污染本源吧？！

**災害**

會發生的災害有地震、洪水、祝融、颶風、怪獸、墜機等。

**其他**

- 機場兼具了太空站的功能，可運輸生活必需品到各太空站、月球的殖民地、火星或星河雲環帶。
- 與美國時期同，一種大型的放射性分解武器取代挖土機的功能。
- 3-P 空間的足球競賽場，有最流行、最刺激的新型比賽，是什麼呢？！等著瞧吧！

#### 入侵月球（p.14–16）

2195 年，地球非常非常地擁擠、雜亂。上至最高的山頂，下至最深的海底，到處都充滿著幾百億的
人口，簡直快爆炸了，如今，唯一的解決辦法就是離開地球到外太空去找個沒有人類居住過的星球，
開墾一片新的天地了。月球，正是人類的新目標，而現在，月球是你的啦，好好利用高科技及科學的
力量，成為史上另一個「名流萬古」的「阿姆斯壯」。

**區域**

由於月球上沒有大氣層，規劃城市的工作很重要，必須將所有的區域，分割成子區域，分佈在有氧氣
出漏的地方，才足以好好生存。

住宅區的範圍從一些簡陋的小房子擴展到高密度的公寓區及都會區；商業區有各式各樣的小商店、
辦公樓、自助餐館、大型商業購物中心等；工業區則有開礦廠，研究中心，及在低引力下最好的
製造業—製藥廠和各種水晶製造廠。

建設 Rover（自由貿易）港，對擴區有很大的幫助，並提高工業區的成長；興建太空梭站則能增加
商業發展。

**能源**

月球上當然沒有煤礦，而且若燃燒煤，會浪費太多的氧氣，氧氣在月球上可是非常地珍貴啊！月球上
也沒有風力及引力可利用，太陽能倒是可行，只是能源不太足，尤其月球大半的時間都是黑暗的。
你有二座電廠可選擇；一座是老式的核能發電廠；另一座是一項新科技的發明—引力波動轉換電廠，
這是利用振動磁場中的黑洞，轉換引力波成為能源，高吧？！

**交通型態**

月球可能不能像它的表哥—地球那樣，有電腦化的自動化交通系統，主要仍是馬路和鐵路系統而已，
不過；因引力很小，所以，月球上另有特別的交通工具，仔細看一下！

**犯罪率和污染**

月球上的人民會發現，地球上的治安實在好多了！在此，你必須好好嚴格執行你的法律，有一大堆
抗爭活動和完美的犯罪等你去處理；破壞者的犯罪手法很可怖，它們會破壞「維生系統」或引爆洞穴
一次殺死好幾千人，好毒喔！

除了工廠、化學工廠的污染外，也要注意一下交通，維生系統及放射線毒氣等帶來的破壞，這些日積月累
的東西可別忽視掉了！

**災害**

會出現的災害有祝融、月震、外星怪獸、流星雨、濾過性病毒所引起的黑死病（與地球上的不同）……等。
但都沒什麼好擔心的！

**其他**

- 因使用放射線武器會太浪費能源，所以只有老式挖土機可用。
- 有空時，多到圓頂公園去休息、休閒一下，躺在草地上呼吸新鮮空氣（這很重要喔，多造點綠地
  提供氧氣！）。
- 體育館的運動都是無引力下舉行的，有興趣去瞧瞧吧？！
- 如果真的，真的很想念地球，教你一個咒語：敲三下膝蓋，唸三次：“沒有地方像這裡這麼完美、
  沒有地方像這裡這麼完美……”。（否則，唸三次：“沒有地方可住了！！”……）
