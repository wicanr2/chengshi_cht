# 電腦休閒世界 024《模擬城市－回到未來系列》中文說明書

## 這是什麼

電腦休閒世界 NO.24，MAXIS 正式授權的台港版資料片，360K 六片裝 NT$260，
外盒標 `ALTERNATE ARCHITECTURE Set 2`，對應原版的 **Future USA／Future Europe／
Moon Colony** 三個圖形集。**內含地形編修程式**，並註明「本遊戲需和 No.22 產品合用」。

說明書 40 頁，分兩篇：

- **PART A（p.3–19）**：資料片本身——安裝、啟動，以及三套未來城市的世界觀與建築對照。
- **PART B（p.20–38）**：地形編修程式篇，是軟體世界 220 那本的重印。

共 37 張掃描。掃描檔**不進版控**（`.gitignore` 擋掉 `docs/manual-cht/scans/`），
本目錄只保存轉錄的文字。

翻譯／羅友志　美編／郭立芝　美術排版／李惠英

## 為什麼它是一手資料

**六種城市風格的中文名，在這一本與 022 之前是本專案自己譯的。** 現在有了 1990 年代
台灣代理商的既有譯法，而且是 MAXIS 授權版：

| 原版圖形集 | 這本說明書怎麼寫 |
|---|---|
| `Future USA` | 美國圖形／U.S.A.★美國／「生在美國」（2055 年）|
| `Future Europe` | 歐洲圖形／ERUOPE★歐陸／「橫掃歐陸」（2155 年）|
| `Moon Colony` | 月球圖形／MOON★月球／「入侵月球」（2195 年）|

各集專屬建築的譯名（雷射競技場、警防部、水翼船港、太空站、核子融爐電廠、
月球警署、太空梭站、自由港、引力波電廠……）逐項列在
[`p01-19-part-a.md`](p01-19-part-a.md) 末三節，取捨記在
[`../naming-crosswalk.md`](../naming-crosswalk.md)。

## 掃描與頁碼的對應

一張掃描是一個跨頁，左頁在前：

```
掃描 _00k → 第 2k−10 頁（左）與第 2k−9 頁（右）　（k = 5…25）
```

`_001` 外盒正面、`_002` 外盒背面、`_003` 書背、`_004` 說明書封底＋封面、
`_026`–`_027` 參考附表、`_028`–`_033` 磁片、`_034`–`_037` 密碼表。
