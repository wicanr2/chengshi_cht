## 就職典禮

### 一、職前介紹（p.1–3）

你好！！ 歡迎加入這個「準市長」的行列！在這個就職典禮上，我要以過來人的
身份，提供各位「新鮮人」一點職前介紹。在各位未來的政治生涯中，你將有兩種
目標選擇：

**第一：建設你個人的「夢想之都」**

> 我們提供三種資金等級（20,000、10,000、5,000）供你建設你夢想中的都市。
> 你可以根據自己的經驗能力，選擇易、中、難三種條件狀況，從一片荒地上默默
> 耕耘，從事工商住宅發展，建設成一座十萬人的大都會（Metropolis），或是
> 五十萬人的大都會區（Megalopolis）。想想看！！當你看到自己的心血成果——
> 工業區四處林立，煙囪高聳入雲；商業區經貿繁華；機場中飛機日夜起降；
> 海港裏商船往來貿易；住宅區車水馬龍……你就知道，你的夢想成真了！

**第二：挽救「悲情城市」**

> 在此有八個城市，不是前任市長留下「爛攤子」，就是即將遭遇不測的災難。
> 在你經驗累積之下，可以選擇重新改造該市，或是局部解決它們的問題，
> 使市民對你，對該市重新燃起信心的火炬。
>
> 在限制的時間內，如果你不負重託，達成市民心中的理想，則市民將頒贈你
> 榮譽市鑰！但是，如果問題沒解決，或是弄得更糟，可別怪市民把你扔出市外，
> 丟在鐵軌上哦！！

好了！！ 相信你們都了解自己的重任所在，接下來要讓各位知道在你治理一個
城市時，你會遭遇到什麼樣的挑戰，有一些在都市計〔字跡不清〕和管理時必須
掌握的因素：

1. **「人」的因素：**
   提供市民居住空間，就業機會和生活的品質。
2. **經濟因素：**
   地價，工商業發展空間，失業問題，內外部市場，電力、稅徵、及公共設施的
   預算編列等。
3. **生存因素：**
   災難、犯罪及污染的應對策略。
4. **政治因素：**
   公眾意見、都市計劃，使市民對你的施政作為感到滿意。

（接下來 p.3 列出五類「工具」，見
[`p03-tools-overview.md`](p03-tools-overview.md)。）

在提出以上參考意見之餘，希望各位了解，所有的因素，以治理者——未來的市長
先生們最重要，善用我們給予的工具和資金，發揮你的聰明才智，相信必可創造更多
市民的幸福富足。不要忘了隨時充實自己，把「參考手冊」仔細閱讀一次，對你會有
最大的幫助！！

### 二、硬體配備（p.4）

1. IBM PC XT／AT 或 100% 相容之機型，主記憶體至少 512K。
   （使用高解析 EGA 螢幕者則需 640K）
2. 磁碟機一台（兩台較佳，有硬碟者更好）。
3. 單色（MGA）或彩色（CGA、EGA）顯示卡。
4. 搖桿、滑鼠（非必備）。
5. IBM 或 Epson 印表機一台（非必備）。
6. 二片格式化過的空白磁片（一片用做遊戲磁片，另一片儲存你所建造的城市檔）。
7. DOS 3.3 以上版本。

### 三、製作遊戲磁片／載入硬碟（p.4–8）

原始母片無法用來直接進入遊戲，你必須藉母片設定電腦的硬體配備，再載入遊戲
磁片或硬碟中，然後用遊戲磁片或硬碟程式來啟動、進入遊戲。因此，每一片遊戲
磁片或硬碟的遊戲程式只能用於固定的硬體配備，若配備有所更動，則須利用母片
重新設定配備，重新製作遊戲磁片或重新載入硬碟。

1. 打開螢幕和主機電源，請務必以 DOS 3.3 以上版本開機。
2. 待 `A>` 出現後，取出 DOS 磁片，將母片 Disk 1 放入 A 磁碟機中，並關好機門。
3. 在 `A>` 之下鍵入 `Install` 按 `ENTER` 鍵。

   ＊以下的各步驟，請使用 `←` `→` 鍵選擇你的配備，選好之後按 `ENTER`
   確定之。若選錯了，可按 `ESC` 鍵重新選擇。

4. 首先選擇母片 Disk 1 所在之磁碟機：

   ```
   Install from drive: 〔*〕A:， 〔 〕B
   ```

   請移動星號選擇 A，按 `ENTER` 鍵，在出現的 `〔N／Y〕:` 之後鍵入 `Y`
   或 `ENTER` 鍵以確定之，或鍵入 `N` 或 `ESC` 跳回去重選。

5. 其次選擇載入的遊戲磁片或硬碟所在的磁碟機代號：

   ```
   Install to drive: 〔 〕A: 〔 〕B: 〔 〕C:
   ```

   a、載入遊戲磁片：

   　　兩台磁碟機：選擇「B」按 `ENTER` 鍵確定之。

   　　一台磁碟機：選擇「A」按 `ENTER` 鍵確定之。

   b、載入硬碟：選擇「C」（或其它硬碟代號），按 `ENTER` 鍵確定之。

6. 接下來出現 `Destination directory ->`

   - 載入遊戲磁片：請按 `ENTER` 鍵跳過本項。
   - 載入硬碟：按 `ENTER` 鍵後，程式會自動在硬碟內開一個名為 `SIMCITY`
     的子目錄。

   其次請鍵入 `Y` 或 `ENTER` 鍵確定選擇，或鍵入 `N` 鍵跳回重選。

7. （選擇載入硬碟的朋友，請跳過此一步驟）

   選擇遊戲磁片的過程可看到以下一段文字：

   ```
   Please insert the destination disk and press ENTER
   ```

   a、第五步驟選擇「A」的朋友，請將 Disk 1 取出，將一片已格式化（Format）
   的磁片放入 A 磁碟機中，關好機門，按 `ENTER` 鍵。

   b、第五步驟選擇「B」的朋友，則請將空白磁片放入 B 磁碟機，關好機門，
   按 `ENTER` 鍵。

8. 選擇螢幕種類：

   〔圖一：安裝程式的螢幕選單畫面，標題列寫 `SIMCITY Install version 1.0`。
   圖說標出六處：左側由上而下是「CGA 四色螢幕」「MGA 單色螢幕」
   「EGA 界面卡的 RAM」「主機的 RAM」，右側是「Tandy 彩色螢幕」
   「EGA 彩色螢幕／顯示型態」，中間下方是「解析度」。
   畫面上讀得出的選項有 `CGA, 640x200 b/w`、`Hercules, 720x348 b/w`、
   `Tandy color, 320x200, 16 color`，以及 `EGA RAM`／`MAIN RAM`／
   `Resolution`／`Display Type` 四欄的組合：
   `256k／128k／128k`、`640k／512k／512k`、
   `640x350 16 color`／`320x200 16 color`／`640x350 b/w`，
   `COLOR`／`COLOR`／`B&W-COLOR`。〕

   使用 EGA 彩色螢幕者，請參考其解析度（Resolution），以及界面卡
   （EGA RAM）和主機（MAIN RAM）記憶容量選擇正確的選項。不過，因為程式
   本身有偵測能力，你只要隨著星號所在位置，核對一下配備，應該錯不了！
   選好後按 `ENTER` 鍵，再按 `Y` 或 `ENTER` 鍵確定之。

9. 選擇是否使用搖桿及其種類：

   | 選項 | 意思 |
   |---|---|
   | `NONE／IGNORE` | 使用鍵盤或滑鼠。 |
   | `IBM／TANDY TYPE` | 使用 IBM 或 Tandy 搖桿。 |
   | `COVOX Sound Master` | 使用 COVOX 音效卡輸出插埠的外接搖桿。 |

   同前，選定後按兩次 `ENTER` 鍵即可確定之。

10. 選擇音效：

    | 選項 | 意思 |
    |---|---|
    | `None` | 不要有音效 |
    | `IBM` | IBM 內藏喇叭 |
    | `Tandy Digital` | Tandy 數位音效 |
    | `COVOX Sound Master` | COVOX 音效 |

    選擇後按兩次 `ENTER` 鍵確定之。

11. 完成以上設定後，你的設定情形都呈列在螢幕左上角由上而下依序為母片所在
    磁碟機、遊戲磁片或硬碟所在的磁碟機、螢幕種類、是否使用搖桿及音效的設定，
    請再檢查一遍後，在 `Is this all correct 〔N／Y〕:` 之後按 `ENTER`
    鍵確定之，或鍵入 `N` 鍵回去重新設定。

12. 在接下來的載入過程中，製作遊戲磁片的朋友請隨時注意畫面上更換磁片的訊息，
    將磁片放入適當的磁碟機中，再按照指示完成載入的步驟。

    ```
    source disk 1 (disk 2) —— 指母片 Disk 1 (disk 2)
    destination disk      —— 指遊戲磁片
    ```

13. 當出現 `A>` 時，即為載入完畢。

## 這幾頁對本專案的用處

**音效那一項是獨立佐證。** 說明書列的四個音效選項（`None`／`IBM`／
`Tandy Digital`／`COVOX Sound Master`）與 `SIMCITY.CFG` 的欄位、
以及 `SETTINGS.EXE` 的選單完全一致。它支持
[`docs/re/16-dos-oracle.md`](../re/16-dos-oracle.md) §4 的結論：
`IBM`（內建喇叭）與另外兩條 DAC 路是**四個並列的選項**，不是同一條路的
不同音質——所以「內建喇叭放的是合成嗶聲、不是 `.PSF` 裡那八段 PCM」
這件事在說明書的分類上也說得通。

**螢幕那一項補上了 CGA 與 Tandy 的存在證明。** 手上這份 DOS 1.10 副本
**缺 CGA 與 Tandy 的資料檔**（見 `docs/formats/00-dos110-inventory.md`），
而 p.7 的圖一直接拍到安裝程式列出這兩種模式。所以那不是我們讀錯設定檔，
是這份副本不完整。
