## 一、前言（p.1）

本地形編修程式提供三個功用：

第一：利用你手頭上能找到的城市地圖，你便能自行編輯該城市地形。這裏提供你一塊
16 公里×16 公里大小的開濶地，供你在市地上設置各種地形——綠地、河流、湖泊、海洋，
編輯好所有的天然地形後，你可將這塊市地載入模擬城市的主程式裏，好好地重新規劃建設，
當你的一市之長。（如何將完成的市地載入主程式中的詳細方法，請自行參閱珍藏版 29
「模擬城市」說明書第 12 頁「2.讀取先前儲存的城市」）

第二：利用本編修程式產生一隨機地形：陸地、海島均可，再進行編修功能，將地形改為
你理想中的市地。

第三：將你在模擬城市主程式裏「搞砸」的城市載入到本程式裏，再利用編修功能將你感到
不滿意的人工建築或地形修改掉。

這可不是作夢哦！只要你敢，你可以當上全球數以千計的大都市市長！不過，這裏也是那些
“落魄市長”重新進修的機會，別錯過了！

## 二、硬體配備（p.2）

1. IBM PC XT/AT 或 100% 相容之機型，主記憶體至少 512K。（選擇 640×350 16 色顯示模式者則需 640K）
2. 磁碟機一台（兩台較佳，有硬碟者更好）。
3. 單色（MGA）或彩色（CGA、EGA、VGA）顯示系統。
4. 搖桿、滑鼠（非必備）。
5. 一片格式化過的空白磁片（作為遊戲磁片之用）。
6. DOS 3.3 以上版本。

## 三、製作遊戲磁片／載入硬碟（p.2–6）

> 原始母片無法用來直接進入遊戲，你必須藉母片設定電腦的硬體配備，再載入遊戲磁片或
> 硬碟中，然後用遊戲磁片或硬碟程式來啟動、進入遊戲。因此，每一片遊戲磁片或硬碟的
> 遊戲程式只能用於固定的硬體配備，若配備有所更動，則須利用母片重新設定配備，重新
> 製作遊戲磁片或重新載入硬碟。

1. 打開螢幕和主機電源，請務必以 DOS 3.3 以上版本開機。
2. 待 A＞出現後，取出 DOS 磁片，將母片 Disk 1 放入 A 磁碟機中，並關好機閂。
3. 在 A＞之下鍵入 Install 按 `Enter` 鍵。
   ＊以下的各步驟，請使用 `←` `→` 鍵選擇你的配備，選好之後按 `Enter` 鍵確定之。
   若選錯了，可按 `Esc` 鍵重新選擇。
4. 首先選擇母片 Disk 1 所在之磁碟機：

   ```
   Install from drive：〔＊〕A:，〔 〕B:
   ```

   請移動星號選擇 A，按 `Enter` 鍵，在出現〔n／Y〕：之後鍵入 `Y` 或 `Enter` 鍵以確定之；
   或鍵入 `N` 鍵跳回去重選。
5. 其次選擇載入的遊戲磁片或硬碟所在的磁碟機代號：

   ```
   Install to drive：〔 〕A:，B:，〔 〕C:
   ```

   - 載入遊戲磁片者：
     - 兩台磁碟機：選擇“B”按 `Enter` 鍵確定之。
     - 一台磁碟機：選擇“A”按 `Enter` 鍵確定之。
   - 載入硬碟者：選擇“C”（或其它硬碟代號），按 `Enter` 鍵確定之。
6. 接下來出現 `Destination directory ->`
   - 載入遊戲磁片者：請按 `Enter` 鍵跳過本項。
   - 載入硬碟者：在輸入狀態下，你可以將子目錄改為其他名字，如 TERRAIN 等，按 `Enter` 鍵，
     或直接按 `Enter` 鍵後，程式會自動在硬碟內開一個名為 SIMCITY 的子目錄。

   其次請鍵入 `Y` 或 `Enter` 鍵確定選擇，或鍵入 `N` 鍵跳回重選。
7. （選擇載入硬碟的朋友，請跳過此一步驟）

   選擇遊戲磁片的過程可看到以下一段文字：

   ```
   Please insert the destination disk and press ENTER
   ```

   - 第 5 步驟選擇“A”的朋友，請將 Disk 1 取出，將一片已格式化（Format）的磁片放入
     A 磁碟機中，關好機閂，按 `Enter` 鍵。
   - 第 5 步驟選擇“B”的朋友，則請將格式化磁片放入 B 磁碟機，關好機閂，按 `Enter` 鍵。
8. 選擇顯示模式：

   畫面上的圖說（由左而右）：CGA 四色螢幕／單色螢幕／VGA、EGA 螢幕；
   Tandy 彩色螢幕／使用 VGA、EGA 螢幕請選擇此一解析度較高者／黑白顯示模式。

   請根據你使用的顯示系統中

   - 顯示卡最小記憶容量（minimum Video RAM）
   - 主機最小記憶容量（minimum MAIN RAM）
   - 解析度（Resolution）
   - 顯示模式（Display Type）

   利用 `←`、`→` 鍵來選擇符合條件的選項，不過，因為程式本身有偵測能力，你只要
   隨著星號所在位置，核對一下配備，應該錯不了！選好後按 `Enter` 鍵，再按 `Y` 或
   `Enter` 鍵確定之；或 `N` 鍵重選。
9. 選擇是否使用搖桿及其種類（Joystick）：

   - NONE／IGNORE：沒有或不使用搖桿。
   - IBM／TANDY Type：使用 IBM 或 Tandy 搖桿。（無搖桿卡或搖桿者切勿選擇此項）
   - COVOX Sound Master：使用 COVOX 音效卡輸出插埠的外接搖桿。

   選定後按兩次 `Enter` 鍵即可確定之。
10. 選擇音效（Sound）：

    - None：不要有音效
    - IBM：IBM 內藏喇叭
    - Tandy Digital：Tandy 數位音效
    - COVOX Sound Master：COVOX 音效

    選擇後按兩次 `Enter` 鍵確定之。
11. 完成以上設定後，你的設定情形都呈列在螢幕左上角由上而下依序為母片所在磁碟機、
    遊戲磁片或硬碟所在的磁碟機、顯示模式、是否使用搖桿及音效的設定，請再檢查一遍後，
    在 `Is this all correct 〔N／Y〕` 之後按 `Enter` 鍵確定之，或鍵入 `N` 鍵回去重新設定。
12. 在接下來的載入過程中，製作遊戲磁片的朋友請隨時注意畫面上更換磁片的訊息，將磁片
    放入適當的磁碟機中，再按照指示完成載入的步驟。

    ```
    source disk 1（disk 2）—— 指母片 Disk 1（disk 2）
    destination disk —— 指遊戲磁片
    ```
13. 載入完畢後，請按空白鍵便可返回 A＞下。

注意：載入時，母片中原有之城市檔（＊.CTY）無法一併載入，你可以使用 COPY 指令將它們
拷入硬碟中（如果硬碟空間足夠的話）；或在遊戲進行時，將母片準備好，以便有時要讀取
母片中的城市檔資料。

## 四、啟動遊戲（p.7）

> ＊啟動遊戲前，請確定已經先執行過“三、製作遊戲磁片／載入硬碟”的步驟。
> ＊欲使用滑鼠或搖桿者，請在啟動遊戲前先安裝好。使用滑鼠者，須先驅動滑鼠程式。

### A、軟式磁碟機

1. 打開電腦及螢幕電源。
2. 以 DOS 3.3 以上版本開機。
3. 待 A＞出現後，取出 DOS 磁片，將載入完畢的遊戲磁片放入 A 磁碟機中，並關好機閂。
4. 在 A＞下鍵入 `TERRAIN` 按 `Enter` 鍵即可。
5. 出現主題畫面之後，請參考第 13 頁“六、視窗”。

### B、硬式磁碟機

1. 打開電腦及螢幕電源。
2. 待 C＞出現後，鍵入 `CD SIMCITY` 按 `Enter` 鍵，進入此遊戲的子目錄中。
3. 待進入子目錄之後，鍵入 `TERRAIN` 按 `Enter` 鍵即可。
4. 出現主題畫面之後，請參考第 13 頁“六、視窗”。

## 五、控制方法（p.8–12）

### A、滑鼠

1. 左滑鼠鈕可執行主要功能，你可藉之：
   - a、打開選單、選擇選項，並執行該功能。
   - b、移動游標到編輯視窗左側任一項圖形，按左滑鼠鈕，再移動游標到視窗中你希望
     放置該圖形的位置上，再按一次鈕即可設置該地形。
2. 右滑鼠鈕在編輯視窗中用以執行“開濶地”（Dirt）圖形功能，即清除地上物。在地圖視窗中
   可用以移動小方框。

（圖：滑鼠示意，標「向上／向下／向左／向右」）

### B、搖桿

如果你要使用搖桿，請選用和 IBM 搖桿 100% 相容者，否則，可能因為不相容而無法操作。

使用方法和滑鼠相同，可用發射鈕 #2 取代滑鼠的左按鈕，用發射鈕 #1 取代右滑鼠鈕，
但搖桿和滑鼠兩者不能同時使用。使用搖桿時若造成畫面跳動而無法移動游標，可按住 `Ctrl` 鍵以解除之。

（圖：搖桿示意，標「向上／向下／向左／向右」）

### C、鍵盤

1. 方向鍵及數字鍵盤：

   | 鍵 | 功能 |
   |---|---|
   | 方向鍵 | 使游標在畫面上下左右移動 |
   | `Ins`、空白鍵 | 功能同滑鼠左按鈕 |
   | `Delete` | 功能同滑鼠右按鈕 |
   | `5` | 使游標停在畫面中央 |
   | `Home` | 使游標停在畫面左側 |
   | `End` | 使游標停在畫面右側 |
   | `PgUp` | 使游標停在畫面頂端 |
   | `PgDn` | 使游標停在畫面底部 |

2. `Ctrl` 鍵加方向鍵或數字鍵盤使城市畫面在編輯視窗下捲動，請先按 `ScrollLock` 鍵
   使螢幕不致因游標在螢幕邊緣而捲動。使用以下指令使畫面依你希望的方向捲動。

   | 組合 | 功能 |
   |---|---|
   | `Ctrl`＋`4` | 使城市畫面向左捲動 |
   | `Ctrl`＋`6` | 使城市畫面向右捲動 |
   | `Ctrl`＋`8` | 使城市畫面向上捲動 |
   | `Ctrl`＋`2` | 使城市畫面向下捲動 |
   | `Ctrl`＋`7`／`Home` | 使城市畫面向左上方捲動 |
   | `Ctrl`＋`1`／`End` | 使城市畫面向左下方捲動 |
   | `Ctrl`＋`9`／`PgUp` | 使城市畫面向右上方捲動 |
   | `Ctrl`＋`3`／`PgDn` | 使城市畫面向右下方捲動 |

3. `＋`、`－` 鍵：

   不使用滑鼠時，則這兩個鍵十分有用，它們可使游標依序選擇選單、視窗中的各選項或
   編輯視窗左側的圖形，因為使用方向鍵移動游標選項較費時。

4. 鍵盤快速功能執行：

   使用以下按鍵，可省略移動游標拉下選單之步驟，而直接執行你所須的功能。

   | 鍵 | 功能 |
   |---|---|
   | `Esc` | 取消、關閉選單或功能 |
   | `F2`、`Alt`＋`S` | 打開系統選單（SYSTEM MENU） |
   | `F3`、`Alt`＋`T` | 打開地形選單（TERRAIN MENU） |
   | `F4`、`Alt`＋`P` | 打開變數選單（PARAMETER MENU） |

   拉下選單後，你可以使用 `↑` `↓` 鍵移動反白區選項。你也可以依照任一選項的起始字母
   選擇按鍵，如有兩項以上起始字母相同，則連續按該鍵便可在這幾項裏輪流選擇。

   有些選項無需拉下選單後選擇，可直接按以下按鍵執行該功能：

   | 鍵 | 功能 |
   |---|---|
   | `Ctrl`＋`A` | 執行平滑功能 |
   | `Ctrl`＋`C` | 清除地圖上所有地形地物 |
   | `Ctrl`＋`E` | 將編輯視窗移到前面 |
   | `Ctrl`＋`I` | 產生島嶼地形 |
   | `Ctrl`＋`L` | 讀取城市選單 |
   | `Ctrl`＋`M` | 將地圖視窗移到編輯視窗前面（`Enter` 鍵亦可） |
   | `Ctrl`＋`R` | 使河流平滑 |
   | `Ctrl`＋`S` | 儲存城市選單 |
   | `Ctrl`＋`T` | 產生隨機地形 |
   | `Ctrl`＋`X` | 跳出遊戲，回到 DOS 下 |
   | `D` | 選擇“開濶地”圖形（無法直接執行，須配合左滑鼠鈕或空白鍵） |

   | `C` | 選擇“航道”圖形（同上） |
   | `F` | 選擇／取消“均佈”功能 |
   | `U` | 執行“回手”功能 |
   | `ScrollLock` | 當你移動游標到螢幕邊緣時，會使編輯視窗內的地形不停捲動，按此鍵可使之停止捲動。 |
   | `Shift` | 設置地形時，將河流、綠地、航道等保持排成一直線。使用時需和左滑鼠鈕（空白鍵或 `Ins` 鍵）同時按住，再以方向鍵控制設置方向，則在設置的直線方向上，即使按了其他方向鍵，也不會被設置。 |

## 六、視窗（p.13–15）

### A、編輯視窗

畫面上的圖說：標題欄、市名、模擬時間；左側由上而下是「圖形」（DIRT／TREES／RIVER／
CHANNEL）、「均佈」（FILL）、「回手」（UNDO）；右側標出「河流（或海）」「航道」
「開濶地」「綠地」；下方是「目前所選之圖形名稱」與「視窗設定鈕」。

1. 標題欄：將游標移到此處，按住左滑鼠鈕（或空白鍵）可以移動整個視窗。
2. 視窗設定鈕：可用以設定視窗的長寬大小。
3. 圖形指令：

   | 鈕 | 名稱 | 說明 |
   |---|---|---|
   | `DIRT` | 開濶地 | 在編輯視窗裏為（圖示），可設置在森林地、水區或其他人工建築上。 |
   | `TREES` | 綠地 | 在編輯視窗裏為（圖示），可設置在任何地形上。 |
   | `RIVER` | 河流 | 在編輯視窗裏為（圖示），可設置在任何地形上。 |
   | `CHANNEL` | 航道 | 在編輯視窗裏為（圖示），必須設置在河流中才有作用。航道必須為連續的，如此，船隻才會隨之航行；此外，航道必須連接到地圖的任一側，在以上兩個條件成立的情況下，再加上一座接通電力的海港，則在模擬城市裏便會產生一條船來。但在模擬城市主程式的地圖上，航道會被隱藏，看來像是一般的水區。為了避免船隻觸礁，請勿將航道設置在陸地上或靠水岸太近。 |
   | `FILL` | 均佈 | 用在大區域裏設置前四種地形的一簡便功能。方法是：<br>a、在地圖或編輯視窗中將你要均佈的區域完整地標示出來（輪廓不可有缺口，必須為連續的界限）。<br>b、選擇要均佈的地形。<br>c、選擇本均佈功能。<br>d、在區域中按左滑鼠鈕或空白鍵即可。如果界限上留有缺口，則全地圖會塗滿該地形，此時，你可選擇 UNDO 回手功能。 |
   | `UNDO` | 回手 | 取消上一步驟，恢復為前一狀態。 |

### B、地圖視窗

地形編修功能同樣可在地圖視窗中執行，你可以利用標題欄移動視窗，將游標移動到標題欄處，
按住左滑鼠鈕（或空白鍵），再以方向鍵（或移動滑鼠），將地圖視窗移動你希望設置的位置，
放開左滑鼠鈕（或空白鍵）即可。（請詳閱第 23 頁“八、注意事項”）

## 七、選單（p.15–22）

選單在畫面上方，共有三種，介紹如下：

### A、系統選單（SYSTEM）

1. **關於本遊戲（About TERRAIN）**：提供本遊戲之相關資料。
2. **印表（Print）**：提供一個選擇視窗以便將你的城市以單頁或多頁印出，但只支援 Epson
   相容性印表機。請移動箭頭選擇多頁市區圖（8－Page Poster）或選擇單頁小地圖
   （1－Page map），按左滑鼠鈕選之，然後將印表機電源打開，再在 `GO` 處按鈕，
   欲取消列印則請選擇 `Cancel`。（圖說：列印視窗）
3. **重新編修——新城市（Start New City）**：產生一片新市地。在清除現有的城市之前，
   會詢問你是否確定。然後為新市地的模擬設定難易程度和名稱。移動游標在名稱欄處按
   左滑鼠鈕或空白鍵成為輸入狀態，再鍵入新市地名稱，按 `Enter` 鍵即可。其次選擇難
   （Hard）、中等（Medium）或簡單（Easy），以便在主程式中建造城市。設定完後，在
   “OK”處按鈕（或空白鍵）即可。（圖說：鍵入市名及選擇難易）
4. **讀取舊有檔案（Load City）**：在“檔案讀取窗”中，可將你先前儲存的城市檔載入進行遊戲。
   - a、先選擇檔案磁片所在之磁碟機代號。假若你把城市檔存在另一片檔案磁片上，
     則請先放入該磁碟座中，在該字母代號上按左滑鼠鈕（或空白鍵、`Ins` 鍵）即可。
   - b、其次在檔名欄中會顯示所有你儲存的城市檔。儲存在硬碟的檔案會以目錄檔顯示在
     代號之後，子目錄以括號顯示之，如果要看子目錄中的程式，可在該目錄檔名上按
     左滑鼠鈕即可。若檔案太多不能一次顯示可在右側的捲動指標箭號處按鈕即可顯示其他的檔案。
   - c、在市名欄內按鈕，成為輸入狀態，請鍵入欲讀取之城市檔名，按 `Enter` 鍵，
     再到“load”處按鈕，即可進入該市地編修。
   - d、不想在此時讀取城市檔，可在“Cancel”處按鈕即可回到上一個畫面。

   （圖說：檔案讀取窗——市名欄／檔案磁片所在之磁碟機座／檔名欄／捲動指標／讀取（LOAD）／取消）
5. **以……檔名儲存現有城市（Save City as）**：在“檔案儲存窗”中，你可以將現正進行的
   市地儲存起來。使用此項功能，你可以儲存一個新市地，或是以不同的檔名儲存起來，
   或是存入不同的磁片或子目錄中。
   - a、先選擇磁碟座。你若已自行準備一片城市檔資料磁片，則將該片 Format 過的磁片
     放入磁碟機中，在該字母代號上按左滑鼠鈕（空白鍵或 `Ins` 鍵）即可。
   - b、決定磁片所在之磁碟座後，在市名欄中按左滑鼠鈕，並鍵入你取的市名，然後在
     “save”處按鈕即可存入。
   - c、在 save 之前，如果你不想在此時儲存本城市檔，可在“Cancel”處按鈕，或直接按 `Esc` 鍵即可。
   - d、使用 `＋`、`－` 鍵可以使你快速找到這些“熱點”以減少移動游標的時間。

   （圖說：檔案儲存窗——市名欄／資料磁片或硬碟所在之字母代號／檔名欄／捲動指標／儲存（SAVE）／取消）
6. **以同一城市檔名儲存（Save City）**：使用此項功能可將現有城市以同名同位址存入。
   但是如果你的城市還沒有取名，而選擇此項功能，則本遊戲會要求你為此城市取名，並指示你儲存之。
7. **跳出遊戲（Exit）**：停止本遊戲，跳回 DOS 下。選擇“Yes”確定之，或“No”取消。

## 八、注意事項（p.23）

1. 本地形編修程式在單色模式裏有些“臭蟲”，請使用單色螢幕者注意以下事項，避免發生當機現象：

   ＊在移動地圖視窗時，請以手冊說明方式確實操作。倘若你在啟動遊戲後，立即移動游標到
   地圖視窗，按了左滑鼠鈕（或空白鍵）後立即鬆開鍵、鈕，則畫面上會出現雜亂的掃描線條，
   請勿緊張！稍待 2～3 分鐘後，線條便會停止掃描，只要你再將地圖視窗移動一下，畫面便會恢復正常。

2. 有搖桿的朋友，當你在載入過程中（Install）選擇了使用搖桿，則請在遊戲中儘可能交互
   使用搖桿和鍵盤。若只使用鍵盤，則在拉下選單的過程，倘若發生當機現象無法移動反白區
   選擇選項，僅須換用搖桿即可繼續遊戲。因此，沒有配備搖桿的朋友，切勿選擇使用搖桿。
