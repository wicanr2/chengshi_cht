# 軟體世界珍藏版 29《模擬城市》中文說明書

## 這是什麼

1990 年代初台灣軟體世界代理 SimCity 時附的中文說明書，56 張掃描（每張一個
跨頁，共約 70 頁）。**遊戲本身沒有中文版**，這本說明書是當年唯一的中文載體，
也是本專案譯名的一手依據。

掃描來源是骨灰集散地（<https://boneash.oldgame.tw>）的「軟體世界說明書補完
計劃」。掃描檔**不進版控**（`.gitignore` 擋掉 `docs/manual-cht/scans/`），
本目錄只保存轉錄的文字。

補完計劃的三個要求（原文附在封存裡）：不得加上其他符號或用來牟利、
掃描前先詢問避免重複、歡迎提供實體遊戲。本專案只引用文字，不散布掃描檔。

⚠ 這批掃描其實是**兩本小冊子**：《操作手冊》（p.1–58）與《參考手冊》
（p.59 起，有自己的封面，在掃描 0033）。頁碼連續編下去，但下面那條
掃描↔頁碼的換算只對第一本成立。

## 頁碼與掃描檔的對應

一張掃描是一個跨頁，左頁在前。第 5 張掃描是第 3、4 頁，所以

```
掃描 k → 第 2k−7 頁（左）與第 2k−6 頁（右）
```

## 轉錄範圍

目前轉錄的是**譯名密度最高的章節**——操作手冊全部（p.23–58）與職前介紹裡
列出工具的那一段（p.3）。那些頁面決定了遊戲內每一個玩家看得到的詞。

《參考手冊》第壹章（模擬模型本身）也轉錄了——它是「規則層算對了沒」的
第二個來源，可以與 Micropolis 原始碼對照。

沒有轉錄的是：p.1–2 與 p.4–8 的安裝步驟（DOS 3.3 時代的磁片操作），
以及《參考手冊》第貳章（都市計劃史的散文，沒有術語也沒有機制）。

⚠ **密碼表不在說明書裡**——它是另外附贈的活頁（p.17 原文：「請拿出附贈的
密碼表」），這批掃描裡沒有，所以沒有東西可以轉錄。
