# 四本中文說明書的譯名對照

本專案手上有四本 1990 年代台灣代理商出的《模擬城市》中文說明書。這一份把它們**對同一件事
各自怎麼稱呼**排在一起，並記下本專案取捨的結果與理由。定案的譯名在
[`../../translations/glossary.md`](../../translations/glossary.md)，這裡只負責**對照與交代**。

## 四本是什麼、誰出的

| 代號 | 書名 | 出版 | 涵蓋 | 本目錄 |
|---|---|---|---|---|
| **珍 029** | 軟體世界珍藏版 29《模擬城市》| 軟體世界 | 原版遊戲操作手冊 ＋ 參考手冊 | [`../`](../)（本目錄根層）|
| **220** | 軟體世界 220《模擬城市 地形編修程式》| 軟體世界 | 地形編輯器（`TERRAIN.EXE`）| [`../sw220-terrain/`](../sw220-terrain/) |
| **休 022** | 電腦休閒世界 022《模擬城市－古城風情系列》| 電腦休閒世界（MAXIS 授權）| 原版操作 ＋ 古亞／中世紀／西部 | [`../chw022-ancient/`](../chw022-ancient/) |
| **休 024** | 電腦休閒世界 024《模擬城市－回到未來系列》| 電腦休閒世界（MAXIS 授權）| 美國／歐洲／月球 ＋ 地形編修程式重印 | [`../chw024-future/`](../chw024-future/) |

## 先講四本之間的關係，否則會把同一份稿當成四份證據

```
原版英文說明書
  ├─ 軟體世界的中文稿 ──┬─ 珍 029（原版操作手冊）
  │                     └─ 220（地形編修程式）
  └─ 電腦休閒世界的中文稿
        ├─ 休 022 第一部份 ← 與軟體世界的稿子逐句相同
        ├─ 休 022 第二部份、城市介紹 ← 電腦休閒世界自己寫的
        ├─ 休 024 PART A ← 電腦休閒世界自己寫的
        └─ 休 024 PART B ← 220 的重印
```

兩件實測到的事：

1. **休 022 的第一部份與珍 029 的譯文逐句相同**，連圖號（圖八 編輯視窗）、
   八個劇本的說明文、「悲情城市」「明日之都」「市鑰」「易如反掌／難易適中／難上加難／
   比登天還難」都對得上。兩家是各自向 MAXIS 取得授權的不同代理商，卻用同一份中文稿。
2. **休 024 的 PART B 是 220 的重印**，只差幾個排版錯誤與被拿掉的交叉引用
   （逐頁比對結果在 [`../chw024-future/p20-40-part-b.md`](../chw024-future/p20-40-part-b.md)）。

所以：**同一段文字在兩本裡出現，不是兩份獨立佐證。** 只有下面標「兩家獨立」的欄位才是。

## 一、原版遊戲的既有譯名：珍 029 vs 休 022

第一部份既然同源，衝突只出現在少數幾處，多半是排字或誤植。定案一律以**珍 029 為準**
（`CLAUDE.md` §3.2 第 1 條，2026-09-04 使用者確認）。

## 四、六個圖形集的專屬建築

這一段是**兩本電腦休閒世界說明書獨有的**，珍 029 與 220 都沒有。
表格照原版訊息檔（`*_MSG.PTF`）的第 1 段（工具列與價目）排，`—` 表示說明書沒給名字。

### 取捨規則（先講清楚，逐條才好判讀）

1. **說明書給了名字就採用**，即使它比英文原文粗一點（`Sumo arena` → 摔角場、
   `Rodeo` → 賽馬場、`Hovercraft Port` → 水翼船港）。這是 `CLAUDE.md` §3.2 第 1、3 條：
   說明書的既有譯名優先，與原文的落差記在備註欄，不默默改掉。
2. **兩種情況不採用**，且逐條寫理由：
   - 說明書自己前後矛盾（月球的兩座電廠）。
   - 採用會讓該圖形集的中文**退回基本檔的用詞**（`Low-G Rec Center` → 體育館），
     那正是 `TestStyleFilesDoNotInheritBaseWording` 在擋的漏改。
3. 說明書用**散文描述**外觀而不是給名字的（泥土路、磚塊路、石板路、高速地下鐵……），
   不改字串，只記在下表的備註欄。

## 五、這一輪沒有動的

- **珍 029 已定案的譯名一律不動**（推土機、鐵軌、悲情城市、明日之都、市鑰、
  預算與評估視窗的欄位……）。休 022 的說法若不同，記在第一節。
- **日文與英文欄不動。** 日文是本專案新譯，1990 年代台灣代理商的中文選字對它不適用；
  英文執行時從玩家自己那份 `.PTF` 讀。
- **散文描述不進字串**（第四節規則 3 那幾條）。
- **密碼表不轉錄**（休 022、休 024、珍 029 各附一張，是原版的手冊查驗表）。
