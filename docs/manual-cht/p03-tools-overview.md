# p.3 — 職前介紹：五類工作

4. 政治因素：

　公眾意見、都市計劃，使市民對你的施政作為感到滿意。

在你建設都市時必須使用到的「工具」，包括有：

1. **規劃** —— 利用地圖系統（Map Systems）來了解並規劃本市
2. **擴展** —— 你必須先設計居住和工作環境，利用道路和鐵路來擴展市區。
3. **建設** —— 設置道路、鐵路、機場、海港、警局、消防隊、運動場和發電廠。
4. **推土機** —— 清除樹林以利用建設，沿水岸建造路基，市地清除及重劃。
5. **管理** —— 利用地圖、統計圖收集每一天的道路密度、污染、人口發展、
   犯罪和警力效率狀況，作為你治理本市的依據。

在提出以上參考意見之餘，希望各位了解，所有的因素，以治理者 —— 未來的
市長先生們最重要，善用我們給予的工具和資金，發揮你的聰明才智，相信必可
創造更多市民的幸福富足。不要忘了隨時充實自己，把「參考手冊」仔細閱讀一次，
對你會有最大的幫助！！
