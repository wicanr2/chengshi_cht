# 翻譯資料

| 檔案 | 內容 |
|---|---|
| [`glossary.md`](glossary.md) | 譯名表，唯一真相 |
| `../internal/i18n/messages/*.tsv` | 遊戲文字的翻譯，**以「段落.索引」為鍵** |

⚠ **訊息翻譯檔放在 `internal/i18n/messages/`，不在這裡。**
`go:embed` 不能跨上層目錄，而遊戲要把文字編進執行檔（發行包不必帶
外部檔案）。放兩份會漂移，所以只留一份，正本在那邊。

## 為什麼以「段落.索引」為鍵

1. **原文不進版控。** 原版的訊息文字屬於原權利人（`CLAUDE.md` §8）。
   骨架只帶鍵與原文長度。
2. **原版 `.PTF` 本來就是分段的**：一段一個用途（狀態訊息、工具造價、
   月份、選單…）。用段落與索引當鍵，就直接對得上原版的結構，
   不必自己發明一套編號。見 [`docs/formats/04-ptf-messages.md`](../docs/formats/04-ptf-messages.md)。
3. **六個圖形集的同一個鍵講同一件事**，只是用詞隨主題不同
   （古代亞洲的「水井」就是基本檔的「發電廠」）。用鍵才對得起來。

## 譯文寫在哪

譯文正本就是 `internal/i18n/messages/*.tsv`。舊的 Python→TOML 產生流程已移除；
`tools/i18n.sh` 現在只檢查原版鍵，使用 `--write` 才會補空列，不覆寫既有譯文。

骨架由 `simtool` 產生：

```bash
tools/go.sh run ./cmd/simtool messages -dos "<DOS 1.10 目錄>" -out translations/messages
```

`len` 欄位是原文的位元組長度，給排版用：中文字寬是英數的兩倍，
譯文超過原文長度就要確認畫面裝得下（`CLAUDE.md` §3.3）。

## 語言資料的格式（2026-08-31 起）

譯文在 [`internal/i18n/messages/`](../internal/i18n/messages/)，**TSV，一列一筆**：

```
key	len	zh_hant	zh_hans	ja
0.0	30	住宅區不足	住宅区不足	住宅地区が足りません
```

`key` 是「段落.索引」，就是原版 `.PTF` 的結構；`len` 是原文的位元組長度
（排版參考，中文字寬是英數的兩倍）。另有一份
[`ui.tsv`](../internal/i18n/messages/ui.tsv)，放 remake 自己的介面字串
（「資金」「需求」那些原版執行檔裡的字），它多一欄 `en`。

**資料片那六份只填「用詞和基本檔不同」的鍵**，其餘留空由退路從基本檔取。
所以資料片的筆數本來就少於基本檔，那不是漏譯；真正的閘門是
`TestStyleFilesDoNotInheritBaseWording`（繁中）與同名的 `Ja` 版——
原文換了字而譯文沒換就會紅。

**這批 TSV 是唯一真相，沒有任何產生器會覆寫它。**
先前是「python 表 → 整檔重寫 toml」，會把直接編在產出檔裡的譯文洗掉
——實際發生過六筆（asia 的「水車」變回「核能發電廠」）。
現在的工具只做兩件事，而且預設空跑：

| 工具 | 做什麼 |
|---|---|
| `tools/i18n.sh` | 比對原版 `.PTF`，列出「原版有、TSV 沒有」的鍵；`--write` 才補空列 |
| `tools/i18n/fill_lang.py zh_hans` | 由繁體**字面**轉簡體，**只填空格子** |

### 四種語言的來歷（不一樣，別混）

| 語言 | 來歷 |
|---|---|
| `zh_hant` | 本專案的翻譯，譯名以軟體世界珍藏版 29 說明書為準 |
| `zh_hans` | 由繁體**字面**轉換（`tools/i18n/hant2hans.py`，428 個字）。**不是用語在地化**——「垃圾掩埋場」沒有改成大陸慣用的「垃圾填埋场」。要改用詞就直接編 TSV，填表工具不會覆蓋 |
| `ja` | **本專案新譯**，不是原版日文版的用語（沒有那份素材）。基本檔全譯，六個資料片各自的用詞也逐條換過（`asia` 的發電廠是「水車」，不是基本檔的「原子力発電所」）|
| `en` | **原版自己的文字**，執行時從玩家那份 `.PTF` 讀，不在版控也不進發行包。只有 `ui.tsv` 那一欄是本專案寫的——`Funds:` 這種字在執行檔裡，原版資料檔給不了 |

退路的順序：資料片的指定語言 → 基本檔的指定語言 → 資料片的繁體 →
基本檔的繁體 → 英文原文 → 空字串。資料片排在基本檔前面，
「水車」才不會被基本檔的「核能發電廠」蓋掉。
